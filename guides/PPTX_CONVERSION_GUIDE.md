## 1. 슬라이드 제작 기본 원칙 및 공통 규칙 (Global Design Rules)

아래의 디자인 및 레이아웃 규칙은 **모든 슬라이드에 예외 없이 동일하게 적용**됩니다.

### 1.1 슬라이드 규격 및 여백
- **화면 비율**: **16:9 와이드스크린 (Widescreen)**
- **정밀 치수**: **`13.333 × 7.500 인치`** (너비 13.333", 높이 7.500" / python-pptx 기준)
- **배경**: **순수 흰색 단색 (`#FFFFFF`)**. 배경 박스, 패널, 그림자, 그라데이션은 일절 사용하지 않음.
- **여백 기준**: 좌우 여백 `0.8 inch`, 하단 여백 `0.5 inch` 이상 필수 확보.

### 1.2 폰트 및 텍스트 컬러 시스템
- **공통 폰트**: **한글 고딕 계열(맑은 고딕, Pretendard, 또는 나눔고딕) 전체 통일**. 슬라이드 내 폰트 혼용 금지.
- **텍스트 컬러 팔레트**:
  | 구분 | 헥스 코드 (HEX) | RGB 값 | 적용 대상 |
  | :--- | :--- | :--- | :--- |
  | **제목 (Dark Charcoal)** | `#111827` | `RGB(17, 24, 39)` | 슬라이드 메인 제목 (거의 검정, Bold) |
  | **부제 (Medium Gray)** | `#6B7280` | `RGB(107, 114, 128)` | 상단 서브헤더(부제), 표지 부제 (회색) |
  | **본문 (Body Charcoal)** | `#1F2937` | `RGB(31, 41, 55)` | 슬라이드 본문 설명 텍스트 (22pt) |
  | **구분선 (Divider Gray)** | `#9CA3AF` | `RGB(156, 163, 175)` | 헤더 하단 가로 실선 (0.75pt / 1px) |
  | **페이지 번호** | `#9CA3AF` | `RGB(156, 163, 175)` | 우측 상단 슬라이드 번호 ("02 / 54") |
  | **배지 배경 (Brand Blue)** | `#1A73E8` | `RGB(26, 115, 232)` | 표지 슬라이드 알약 모양 배지 |
  | **코드 박스 배경 (Black)** | `#111827` | `RGB(17, 24, 39)` | 와이드 터미널 박스 배경 (순수 다크 차콜) |
  | **코드 텍스트 (White)** | `#FFFFFF` | `RGB(255, 255, 255)` | 코드 블록 내부 파이썬 코드 글자 (13~14pt) |

### 1.3 금지 사항 (Strict Prohibitions)
- ❌ **텍스트 크기 임의 축소 금지** (지정된 포인트 준수)
- ❌ **요소 겹침(Overlap) 금지**
- ❌ **장식용 임의 선, 도형, 클립아트 추가 금지**
- ❌ **파란색/유색 박스 배경 또는 카드 패널 사용 금지** (완전한 화이트 스튜디오 플랫 디자인)

## 2. 표지 슬라이드 규격 (Cover Slide Specification)

표지 슬라이드는 배경 패널 없이 순백색 캔버스 위에서 좌측 타이포그래피와 우측 캐릭터 애셋이 수평적으로 완벽한 균형을 이루도록 구성합니다.

```
[표지 슬라이드 레이아웃 구조]
┌────────────────────────────────────────────────────────────────────────┐
│  [배지: 파란 알약 모양, 흰 글씨 14pt Bold]                             │
│                                                                        │
│  [제목: 44pt Bold, #111827]                     [캐릭터 애셋 존]       │
│                                                 (동일한 바닥선에 맞춰   │
│  [부제: 20pt 회색, #6B7280]                      나란히 배치)          │
│                                                                        │
│  [강사 정보: 16pt]                              [지니][도로시][토토][교수님]│
└────────────────────────────────────────────────────────────────────────┘
```

- **좌측 영역 (Typography Zone)**:
  - **배지 (Badge)**: 파란색 알약 모양 (`#1A73E8`, Rounded Rectangle), 흰색 글씨 **`14pt Bold`**
  - **강의 제목 (Main Title)**: **`44pt Bold`** (`#111827`), 왼쪽 정렬
  - **부제목 (Subtitle)**: **`20pt Regular`** (`#6B7280`), 왼쪽 정렬
  - **강사 서명 (Author Info)**: `16pt Regular` (`#374151`)
- **우측 영역 (Character Assets Zone)**:
  - 캐릭터 이미지들을 **동일한 바닥선(Ground Line, 예: y=5.8" ~ 6.0")에 맞춰 나란히 배치**.
  - 배경 패널이나 박스 없이, [`/Users/hojin9/dev/jinysite/강화학습3/guides/cover_assets.md`](file:///Users/hojin9/dev/jinysite/강화학습3/guides/cover_assets.md) 규격에 따라 단독 전신 투명 PNG 애셋(`assets/*.png`)을 개별 Picture 객체로 삽입.

## 3. 본문 슬라이드 정밀 레이아웃 규격 (Body Slide Layout)

모든 본문 슬라이드는 **동일한 위치의 고정 헤더 영역**과 **좌우 2단 분할의 본문 영역**으로 구성됩니다.

```
[본문 슬라이드 레이아웃 구조 (13.333" x 7.500")]
0.8"                                                           12.53"
 ┌───────────────────────────────────────────────────────────────┐
 │ 제목: x 0.8, y 0.4, 32pt Bold              페이지 번호: x 11.33│ 0.4"
 │ 부제: x 0.8, y 1.05, 20pt 회색             y 0.5, 14pt (02/54)│ 1.05"
 │───────────────────────────────────────────────────────────────│ y 1.7 (0.75pt)
 │                                                               │
 │   [이미지 영역]                  [본문 텍스트 영역]          │ y 2.0
 │   x 1.0, y 2.0                   x 6.6, y 2.0                 │
 │   4.4 x 4.4 inch                 폭 5.9 inch, 22pt            │
 │   정사각형 (비율 유지)           줄 간격 150%, 상하 가운데    │
 │                                                               │
 │   [캡션 영역]                                                 │ y 6.4
 │   이미지 아래 y 6.4, 11pt                                     │
 └───────────────────────────────────────────────────────────────┘
```

### 3.1 헤더 영역 (Header Zone - 모든 본문 슬라이드 고정)
- **제목 (Title)**: `x = 0.8"`, `y = 0.4"`, 폭 `10.5"`, 높이 `0.55"` / **`32pt Bold`**, 왼쪽 정렬, 한 줄
- **부제 (Subtitle)**: `x = 0.8"`, `y = 1.05"`, 폭 `10.5"`, 높이 `0.45"` / **`20pt Regular`**, 회색 (`#6B7280`), 한 줄
- **페이지 번호 (Page Number)**: 오른쪽 위 `x = 11.33"`, `y = 0.5"`, 폭 `1.2"`, 높이 `0.4"` / **`14pt Bold`**, `"02 / 54"` 형식, 오른쪽 정렬
- **구분선 (Divider Line)**: `y = 1.7"`, 가로 `x = 0.8"` ~ `12.53"` (길이 11.733"), 색상 **`#9CA3AF`**, 굵기 **`0.75pt (1px)`**, 실선 (`add_connector(MSO_CONNECTOR.STRAIGHT)`, 그림자/효과 없음)

---

### 3.2 본문 영역 (Body Content Zone - y 2.0" ~ 6.4")
이미지 왼쪽, 텍스트 오른쪽의 **엄격한 2단 구성**을 적용합니다:

#### 1) 좌측 이미지 영역
- **좌표 및 크기**: `x = 1.0"`, `y = 2.0"`, **`4.4 × 4.4 inch`** 정사각형 바운딩 박스.
- **비율 유지**: 원본 이미지의 가로세로 비율(Aspect Ratio)을 100% 유지하며, 절대 늘리거나 찌그러뜨리지 않음. 박스 내 중앙 정렬 배치.
- **캡션 (Caption)**: 이미지 바로 아래 **`y = 6.4"`**, 폭 `4.4"`, 높이 `0.5"` / **`11pt Regular`**, 색상 `#4B5563`, 가운데 정렬, **최대 2줄 이내**.

#### 2) 우측 본문 텍스트 영역
- **좌표 및 크기**: `x = 6.6"`, `y = 2.0"`, **폭 `5.9 inch`**, 높이 `4.4 inch`.
- **타이포그래피**: **`22pt`**, 텍스트 색상 **`#1F2937`**.
- **정렬 및 행간**: **줄 간격 `150%`**, 왼쪽 정렬, 텍스트 상자 내 **상하 수직 가운데 정렬 (Vertical Centering)**.
- **가독성 보장**: 문장이 지나치게 길어지지 않도록 단락별 여백을 유지하며 시각적 위계를 확보.

### 3.3 코드 블록 영역 규격: 와이드 터미널 박스 및 들여쓰기 보존 규칙

> **[코드 블록 레이아웃 원칙: 와이드스크린 전체 활용 + 고해상도 가독성 확보]**  
> 파이썬 코드 블록은 슬라이드 중앙에 작은 정사각형으로 웅크려 배치하지 않고, **슬라이드의 가로 작업 영역 전체(Wide Dark Terminal Box, 폭 11.733")를 시원하게 활용**하여 텍스트가 줄바꿈되거나 주석이 잘리지 않도록 합니다.

- **와이드 터미널 박스 치수 및 배치 (코드 단독 슬라이드)**:
  - **좌표 및 크기**: `x = Inches(0.8)`, `y = Inches(2.0)`, **`폭 11.733 inch`**, **`높이 4.9 inch`** (구분선 너비와 정확히 일치).
  - **배경 및 외곽선**: 순수 다크 차콜 (`#111827`), 미세 테두리선 (`#374151`, 1pt).
  - **내부 여백 (Padding)**: 상하 `0.3 inch`, 좌우 `0.4 inch`.
- **2단 분할 코드 박스 (좌측 코드 + 우측 설명문 슬라이드)**:
  - 좌측 코드 터미널: `x = Inches(0.8)`, `y = Inches(2.0)`, `폭 5.8 inch`, `높이 4.8 inch`.
  - 우측 설명 텍스트: `x = Inches(6.9)`, `y = Inches(2.0)`, `폭 5.6 inch`, `높이 4.8 inch`.
- **코드 텍스트 및 들여쓰기(Indentation) 보존 3대 기술 원칙**:
  1. **고정폭(Monospace) 코딩 폰트 의무 적용 (`Consolas`)**:
     - 가변폭 폰트는 스페이스(` `)의 폭이 글자의 20~25%로 극단적으로 좁아 들여쓰기가 납작하게 뭉개집니다.
     - 반드시 고정폭 폰트인 **`Consolas`**를 적용하여 공백 4칸(`    `)이 영문 4글자와 완벽히 동일한 폭을 갖도록 보장합니다.
  2. **선행 공백의 유니코드 불분절 공백(`\u00A0`, Non-Breaking Space) 변환**:
     - 파워포인트 텍스트 프레임 렌더러가 선행 공백을 자동 압축(Collapse)하거나 공백에서 임의 줄바꿈하는 결함을 방지합니다.
     - 각 줄의 시작 부분에 위치한 모든 들여쓰기 공백을 `\u00A0`으로 변환하여, 클래스/함수/조건문의 4칸·8칸 들여쓰기 계층 구조를 100% 보존합니다.
  3. **OpenXML `xml:space="preserve"` 속성 명시적 주입**:
     - OpenXML 표준(ECMA-376)에 따라 `<a:t>` 텍스트 엘리먼트에 `xml:space="preserve"` 속성을 강제 주입하여 파워포인트 엔진이 공백을 일절 손실하지 않도록 합니다.
- **폰트 크기 및 줄 간격 (가독성 최우선)**:
  - 폰트 크기: **`Pt(13.0)` ~ `Pt(14.0)`** (단독 와이드 슬라이드 기준. 줄 수가 12줄 내외일 때 최적의 가독성 제공).
  - 텍스트 색상: **순백색 (`#FFFFFF`, Pure White)**.
  - 줄 간격: **`125% ~ 130%`**, 문단 간격 `0pt`.
  - 텍스트 래핑: `word_wrap = False` (줄 중간에서 어색한 꺾임 방지).

### 3.4 코드 분할(Code Chunking) 및 강의 스크립트 분할 동기화 절대 원칙

> **[코드 및 스크립트 분할 원칙: 15줄 초과 코드 우겨넣기 절대 금지]**  
> 긴 소스코드를 폰트만 9pt 이하로 줄여 한 슬라이드에 모두 담는 것은 가독성을 완전히 파괴합니다. 소스코드가 12~15줄을 초과하는 경우 **반드시 논리적 기능 단위로 여러 슬라이드로 분리**하고, **강의 스크립트(Notes)도 각 슬라이드의 코드에 맞춰 함께 분할**해야 합니다.

1. **논리적 분할 기준**:
   - `__init__`, `get_action`, `update` 등의 메서드 단위 분리.
   - 긴 메서드(예: `update`)는 기능적 단계로 분리:
     - **Part 1 (1/2)**: 입력 인자 및 경험 버퍼(`deque`) 저장, 데이터 충족 여부 조기 반환(`if len(memory) < 2: return`), 종단 상태 판정.
     - **Part 2 (2/2)**: 중요도 샘플링 가중치 $\rho$ 계산, TD 목표치 도출 및 $Q$ 테이블 갱신, 정책 비대칭 개선.
   - 슬라이드 부제에 `(1/2)`, `(2/2)` 명시.
2. **강의 스크립트(Slide Notes) 분할 동기화**:
   - 분할된 각 슬라이드에는 해당 코드 스니펫의 원리와 역할을 50초 내외로 구체적으로 설명하는 고품질 교수님 강의 스크립트를 독립적으로 작성하여 슬라이드 노트에 삽입.
   - 앞선 슬라이드와 자연스럽게 연결되면서도 해당 슬라이드의 코드를 한 줄씩 짚어주는 구술 스크립트 제공.

### 3.5 텍스트 과다 슬라이드의 다중 슬라이드 분할 원칙 (Text Overflow Splitting)

> **[텍스트 오버플로우 방지 원칙: 슬라이드 편집 영역 이탈 원천 차단]**  
> 슬라이드 본문 텍스트가 많아 슬라이드 편집 하단 한계선(`y = 6.4"`)을 벗어나는 경우, 폰트를 임의로 줄이지 않고 **반드시 2개 이상의 슬라이드로 분할(`(1/2)`, `(2/2)`)**하여 작성합니다.

- **슬라이드당 적정 텍스트 분량**:
  - 글머리 기호(Bullet): **최대 4 ~ 5개 이내**.
  - 전체 본문 글자 수: **250 ~ 300자 이내** (22pt, 줄 간격 150% 기준 `y = 2.0" ~ 6.4"` 영역에 안락하게 수용).
- **분할 작성 방법**:
  - 소주제 또는 논리적 순서에 따라 본문 단락을 전반부/후반부로 분할.
  - 슬라이드 제목/부제에 `(1/2)`, `(2/2)`를 부기하여 청중과 강사가 연속된 맥락임을 인지하도록 구성.
  - 슬라이드 노트(강의 스크립트) 역시 각 슬라이드 분량에 맞추어 분할 작성.

## 4. 슬라이드 본문 수식 변환 엔진 (LaTeX / HTML → Clean Unicode)

> **[수식 변환 절대 원칙: 슬라이드 내 원화 기호(₩) 및 백슬래시(\) 완전 박멸]**  
> 윈도우 환경 및 한국어 폰트(맑은 고딕, 나눔고딕 등)에서 백슬래시(`\`)는 원화 기호(`₩`)로 강제 매핑되어 화면에 `₩varepsilon(10%)`, `₩rho`, `₩gamma`와 같은 흉측한 코드로 노출됩니다. 따라서 슬라이드 본문 렌더링 시 **모든 LaTeX 문법과 백슬래시 기호는 100% 예외 없이 미려한 유니코드 수학 기호 및 일반 텍스트로 완전 변환**되어야 합니다.

1. **LaTeX 특수 그리스 문자 및 연산자 매핑**:
   - `\varepsilon`, `\epsilon` $\to$ **`ε`** (특히 `\varepsilon(10%)` $\to$ `ε(10%)` 필수 변환)
   - `\rho` $\to$ **`ρ`**, `\gamma` $\to$ **`γ`**, `\alpha` $\to$ **`α`**, `\delta` $\to$ **`δ`**, `\theta` $\to$ **`θ`**, `\sigma` $\to$ **`σ`**, `\pi` $\to$ **`π`**
   - `\sum` $\to$ **`∑`**, `\mathbb{E}` / `\mathbb E` $\to$ **`E`**
   - `\rightarrow`, `\to`, `\xrightarrow{...}` $\to$ **`→`**, `\leftarrow` $\to$ **`←`**, `\implies` $\to$ **`⇒`**
   - `\times` $\to$ **`×`**, `\cdot` $\to$ **`·`**, `\approx` $\to$ **`≈`**, `\le` / `\leq` $\to$ **`≤`**, `\ge` / `\geq` $\to$ **`≥`**, `\neq` $\to$ **`≠`**, `\in` $\to$ **`∈`**, `\sim` $\to$ **`~`**, `\mid` $\to$ **`|`**
   - `\dots`, `\cdots`, `\hellip`, `&hellip;` $\to$ **`…`**
   - `\max_a`, `\maxa` $\to$ **`max_a`**, `\argmax`, `\arg\max` $\to$ **`argmax`**
2. **복합 수식 문법 언래핑 (Unwrapping)**:
   - 분수: `\frac{A}{B}` $\to$ **`(A) / (B)`** (중첩 중괄호 `{t+1}` 대응 재귀/스택 파싱 적용)
   - 크기 조절 괄호: `\left(`, `\right)`, `\left[`, `\right]`, `\left\{`, `\right\}` $\to$ **`(`, `)`, `[`, `]`, `{`, `}`**, `\left.`, `\right.` $\to$ **공백 제거**
   - 텍스트/서체 태그: `\text{...}`, `\mathbf{...}`, `\operatorname{...}` $\to$ **내부 내용만 추출**
   - 모자 기호: `\hat{v}` $\to$ **`v̂`** (또는 `v`)
3. **첨자 및 마크다운 기호 정제**:
   - `<sub>t</sub>` $\to$ `_t`, `<sub>t+1</sub>` $\to$ `_{t+1}`, `<sup>2</sup>` $\to$ `²`
   - 마크다운 기호(`*`, `` ` ``, `$`) 완전 제거
4. **최종 안전망 (Sanitization Pass)**:
   - 위 변환을 거친 후 남아 있는 모든 `\word` 형태의 잔여 LaTeX 명령어(`re.sub(r"\\[a-zA-Z]+", "", text)`)와 **모든 백슬래시 문자(`\`)를 100% 제거**하여 원화 기호(`₩`)가 단 1개도 노출되지 않도록 보장합니다.

## 5. 슬라이드 노트(강의 스크립트)의 TTS 음성 발음 최적화 표준

슬라이드 노트(Notes Page)는 **향후 음성 합성(TTS) 엔진으로 낭독될 강의 스크립트**이므로, 수식 코드가 아닌 **자연스러운 한국어 구술 독음 표준**으로 100% 변환하여 삽입합니다:

| 원본 수식/코드 기호 | TTS 음성 구술 표준 텍스트 | 자연스러운 발음 예시 |
| :--- | :--- | :--- |
| **`\varepsilon` / `\epsilon` / `ε`** | **`입실론`** (예: `ε(10%)` $\to$ `입실론 10%`) | "강제로 입실론 10%의 무작위 탐색을 감수해야 했고..." |
| **`\rho` / `ρ`** | **`로`** (예: `ρ = 1.0` $\to$ `로 1.0`) | "1-스텝 중요도 가중치 로를 구하여..." |
| **`\gamma` / `γ`** | **`할인율 감마`** 또는 **`감마`** | "할인율 감마가 차수별로 곱해지는..." |
| **`\alpha` / `α`** | **`학습률 알파`** 또는 **`알파`** | "오차 항에 학습률 알파를 곱해서..." |
| **`\delta_t` / `δ_t`** | **`시간차 오차 델타티`** | "새로운 기준점과의 간격인 시간차 오차 델타티를..." |
| **`\pi` / `π`** | **`파이`** 또는 **`정책 파이`** | "최적 대상 정책 파이와 탐색 정책 비의..." |
| **`\sum` / `∑`** | **`시그마 합`** | "모든 미래 사건의 확률적 시그마 합을..." |
| **`\mathbb{E}` / `E[...]`** | **`기댓값 이`** | "조건부 기댓값 이의 형태로 정의됩니다." |
| **`$G_t$` / `G_t`** | **`수익 지티(G_t)`** 또는 **`지티`** | "수익 지티의 정의를 다시 칠판에 적어보겠습니다." |
| **`$G_{t+1}$`** | **`다음 시점의 수익 지티 플러스 원`** | "다음 시점의 수익 지티 플러스 원에 할인율을 곱한..." |
| **`$R_t$` / `R_t`** | **`즉각 보상 알티(R_t)`** 또는 **`알티`** | "당장 받는 즉각 보상 알티와..." |
| **`$R_{t+1}$`** | **`즉각 보상 알티 플러스 원`** | "행동 직후 관측된 즉각 보상 알티 플러스 원과..." |
| **`$S_t$` / `$S_{t+1}$`** | **`현재 상태 에스티` / `다음 상태 에스티 플러스 원`** | "에스티에서 한 걸음 내딛어 에스티 플러스 원에..." |
| **`$A_t$` / `$A_{t+1}$`** | **`행동 에이티` / `다음 행동 에이티 플러스 원`** | "선택된 행동 에이티와 다음 행동 에이티 플러스 원..." |
| **`$v_\pi(s)$`** | **`상태 가치 브이 파이 오브 에스`** | "정책 파이를 따를 때의 상태 가치 브이 파이 오브 에스는..." |
| **`$q_\pi(s, a)$`** | **`행동 가치 큐 파이 오브 에스 에이`** | "상태 에스에서 행동 에이를 취할 때의 행동 가치..." |
| **`$V(S_t)$` / `$V(S_{t+1})$`** | **`현재 가치 브이 오브 에스티` / `다음 가치 브이 오브 에스티 플러스 원`** | "현재의 가치 추정치 브이 오브 에스티에..." |
| **`$Q(S_t, A_t)$`** | **`큐 오브 에스티 에이티`** | "현재의 행동 가치 큐 오브 에스티 에이티를..." |
| **`\max_a` / `max_a`** | **`맥스 에이`** | "다음 상태에서 취할 수 있는 최댓값인 맥스 에이를..." |
| **`\argmax` / `argmax`** | **`아그맥스`** | "최고 점수를 주는 최선의 행동을 아그맥스로 즉시 선택..." |
| **`\frac{A}{B}`** | **`B 분의 A`** (예: `\frac{\pi}{b}` $\to$ `비 분의 파이`) | "행동 정책 비 분의 대상 정책 파이의 비율로..." |
| **`\leftarrow` / `←` / `<-`** | **`로 갱신`** 또는 **`대입하여 갱신`** | "계산된 타깃 값으로 큐 테이블을 갱신합니다." |
| **`\approx` / `≈`** | **`약`** 또는 **`근사값`** | "이상적인 참값에 약 일치하도록..." |
| **`eval()`** | **`이밸 메서드`** | "한 걸음 걸을 때마다 이밸 메서드를 호출하여..." |
| **`done == True`** | **`던 플래그가 참일 때`** | "에피소드가 끝나서 던 플래그가 참일 때..." |

## 6. `python-pptx` 표준 구현 코드 스펙

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN, MSO_ANCHOR
from pptx.enum.shapes import MSO_CONNECTOR, MSO_SHAPE

prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.500)

FONT_NAME = "나눔고딕" # 또는 "맑은 고딕", "Pretendard"
COLOR_TITLE = RGBColor(17, 24, 39)    # #111827 (거의 검정)
COLOR_SUBTITLE = RGBColor(107, 114, 128) # #6B7280 (회색)
COLOR_BODY = RGBColor(31, 41, 55)     # #1F2937
COLOR_DIVIDER = RGBColor(156, 163, 175) # #9CA3AF (실선)
COLOR_BRAND = RGBColor(26, 115, 232)  # #1A73E8 (배지)

# ==========================================
# 1. 헤더 영역 생성 (모든 본문 슬라이드 동일 적용)
# ==========================================
def add_header(slide, title_text, subtitle_text, page_str):
    # 제목: x 0.8, y 0.4, 32pt Bold, 왼쪽 정렬, 한 줄
    t_box = slide.shapes.add_textbox(Inches(0.8), Inches(0.4), Inches(10.5), Inches(0.55))
    tf = t_box.text_frame
    tf.word_wrap = True
    p = tf.paragraphs[0]
    p.text = title_text
    p.font.name = FONT_NAME
    p.font.size = Pt(32)
    p.font.bold = True
    p.font.color.rgb = COLOR_TITLE

    # 부제: x 0.8, y 1.05, 20pt 회색, 한 줄
    s_box = slide.shapes.add_textbox(Inches(0.8), Inches(1.05), Inches(10.5), Inches(0.45))
    sf = s_box.text_frame
    sf.word_wrap = True
    sp = sf.paragraphs[0]
    sp.text = subtitle_text
    sp.font.name = FONT_NAME
    sp.font.size = Pt(20)
    sp.font.color.rgb = COLOR_SUBTITLE

    # 페이지 번호: 오른쪽 위 x 11.33, y 0.5, 14pt ("02 / 54")
    num_box = slide.shapes.add_textbox(Inches(11.333), Inches(0.5), Inches(1.2), Inches(0.4))
    np_p = num_box.text_frame.paragraphs[0]
    np_p.text = page_str
    np_p.font.name = FONT_NAME
    np_p.font.size = Pt(14)
    np_p.font.color.rgb = COLOR_DIVIDER
    np_p.alignment = PP_ALIGN.RIGHT

    # 구분선: y 1.7, 가로 x 0.8 ~ 12.53, 색 #9CA3AF, 굵기 0.75pt(1px)
    line = slide.shapes.add_connector(
        MSO_CONNECTOR.STRAIGHT, Inches(0.8), Inches(1.7), Inches(12.533), Inches(1.7)
    )
    line.line.color.rgb = COLOR_DIVIDER
    line.line.width = Pt(0.75)

# ==========================================
# 2. 본문 영역 생성 (2단 구성: 이미지 좌, 텍스트 우)
# ==========================================
def add_body_2column(slide, image_path, caption_text, body_text):
    # 이미지: x 1.0, y 2.0, 4.4 x 4.4inch 정사각형 비율 유지
    if image_path:
        slide.shapes.add_picture(image_path, Inches(1.0), Inches(2.0), width=Inches(4.4))

    # 캡션: 이미지 아래 y 6.4, 11pt, 가운데 정렬
    if caption_text:
        c_box = slide.shapes.add_textbox(Inches(1.0), Inches(6.4), Inches(4.4), Inches(0.5))
        cp = c_box.text_frame.paragraphs[0]
        cp.text = caption_text
        cp.font.name = FONT_NAME
        cp.font.size = Pt(11)
        cp.font.color.rgb = RGBColor(75, 85, 99)
        cp.alignment = PP_ALIGN.CENTER

    # 본문 텍스트: x 6.6, y 2.0, 폭 5.9inch, 22pt, 줄 간격 150%, 상하 가운데 정렬
    t_box = slide.shapes.add_textbox(Inches(6.6), Inches(2.0), Inches(5.9), Inches(4.4))
    tf = t_box.text_frame
    tf.word_wrap = True
    tf.vertical_anchor = MSO_ANCHOR.MIDDLE
    tp = tf.paragraphs[0]
    tp.text = body_text
    tp.font.name = FONT_NAME
    tp.font.size = Pt(22)
    tp.font.color.rgb = COLOR_BODY
    tp.line_spacing = 1.5

# ==========================================
# 3. 코드 블록 생성 (와이드 다크 터미널 박스 + 완벽한 들여쓰기)
# ==========================================
def add_code_wide_box(slide, code_text, left=Inches(0.8), top=Inches(2.0), width=Inches(11.733), height=Inches(4.9)):
    # 다크 차콜 와이드 터미널 배경 박스
    box = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, left, top, width, height)
    box.fill.solid()
    box.fill.fore_color.rgb = RGBColor(17, 24, 39) # #111827
    box.line.color.rgb = RGBColor(55, 65, 81)      # #374151
    box.line.width = Pt(1)
    
    # 흰색 코드 텍스트 (Consolas 고정폭 + \u00A0 들여쓰기)
    tf = box.text_frame
    tf.word_wrap = False
    tf.margin_left = Inches(0.4)
    tf.margin_top = Inches(0.3)
    tf.margin_right = Inches(0.4)
    tf.margin_bottom = Inches(0.3)
    
    for i, line in enumerate(code_text.rstrip().split("\n")):
        p = tf.paragraphs[0] if i == 0 else tf.add_paragraph()
        leading_spaces = len(line) - len(line.lstrip(" "))
        preserved_line = ("\u00A0" * leading_spaces) + line.lstrip(" ")
        p.text = preserved_line
        p.font.name = "Consolas"
        p.font.size = Pt(13)
        p.font.color.rgb = RGBColor(255, 255, 255) # 흰색
        p.line_spacing = 1.25

        # OpenXML xml:space="preserve" 주입
        for r in p._p.xpath(".//a:t"):
            r.set("{http://www.w3.org/XML/1998/namespace}space", "preserve")
```
