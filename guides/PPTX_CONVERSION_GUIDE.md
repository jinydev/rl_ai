# 교재 슬라이드(slides.md) 기반 PPTX 변환 및 제작 마스터 가이드

본 가이드는 [`slides.md`](file:///Users/hojin9/dev/jinysite/강화학습3/src/10_TD법/10_1_TD법으로_정책_평가하기/slides.md) 문서를 입력받아 고품질의 강의용 파워포인트(PPTX) 프레젠테이션 파일로 변환 및 제작하기 위한 표준 규격서입니다. 16:9 와이드스크린 레이아웃, 헤더/본문/표지의 엄격한 좌표 및 타이포그래피 시스템, 동일 디렉토리 내 16:9 커버 이미지 기반 편집 가능 표지 슬라이드, 2단 분할 레이아웃, **슬라이드 노트(강의 스크립트)의 향후 TTS(음성 합성) 발음 최적화 구술 변환 규칙**을 총망라합니다.

## 1. 슬라이드 제작 기본 원칙 및 공통 규칙 (Global Design Rules)

아래의 디자인 및 레이아웃 규칙은 **모든 슬라이드에 예외 없이 동일하게 적용**됩니다.

### 1.1 슬라이드 규격 및 여백
- **화면 비율**: **16:9 와이드스크린 (Widescreen)**
- **정밀 치수**: **`13.333 × 7.500 인치`** (너비 13.333", 높이 7.500" / python-pptx 기준)
- **배경**: **순수 흰색 단색 (`#FFFFFF`)**. 배경 박스, 패널, 그림자, 그라데이션은 일절 사용하지 않음.
- **여백 기준**: 좌우 여백 `0.8 inch`, 하단 여백 `0.5 inch` 이상 필수 확보.

### 1.2 폰트 및 텍스트 컬러 시스템
- **공통 폰트**: **한글 고딕 계열(맑은 고딕, Pretendard, 또는 나눔고딕) 전체 통일**. 슬라이드 내 폰트 혼용 금지.
- **텍스트 컬러 팔레트**:
  | 구분 | 헥스 코드 (HEX) | RGB 값 | 적용 대상 |
  | :--- | :--- | :--- | :--- |
  | **제목 (Dark Charcoal)** | `#111827` | `RGB(17, 24, 39)` | 슬라이드 메인 제목 (거의 검정, Bold) |
  | **부제 (Medium Gray)** | `#6B7280` | `RGB(107, 114, 128)` | 상단 서브헤더(부제), 표지 부제 (회색) |
  | **본문 (Body Charcoal)** | `#1F2937` | `RGB(31, 41, 55)` | 슬라이드 본문 설명 텍스트 (22pt) |
  | **구분선 (Divider Gray)** | `#9CA3AF` | `RGB(156, 163, 175)` | 헤더 하단 가로 실선 (0.75pt / 1px) |
  | **페이지 번호** | `#9CA3AF` | `RGB(156, 163, 175)` | 우측 상단 슬라이드 번호 ("02 / 54") |
  | **배지 배경 (Brand Blue)** | `#1A73E8` | `RGB(26, 115, 232)` | 표지 슬라이드 알약 모양 배지 |
  | **코드 박스 배경 (Black)** | `#111827` | `RGB(17, 24, 39)` | 와이드 터미널 박스 배경 (순수 다크 차콜) |
  | **코드 텍스트 (White)** | `#FFFFFF` | `RGB(255, 255, 255)` | 코드 블록 내부 파이썬 코드 글자 (13~14pt) |

### 1.3 금지 사항 (Strict Prohibitions)
- ❌ **텍스트 크기 임의 축소 금지** (지정된 포인트 준수)
- ❌ **요소 겹침(Overlap) 금지**
- ❌ **장식용 임의 선, 도형, 클립아트 추가 금지**
- ❌ **파란색/유색 박스 배경 또는 카드 패널 사용 금지** (완전한 화이트 스튜디오 플랫 디자인)

## 2. 표지 슬라이드 규격 (Cover Slide Specification)

표지 슬라이드는 **커버 이미지를 약 84.5% 비율로 축소하여 오른쪽 하단(Right-Bottom)에 고정**하고, **좌측 상단에 넓은 여백을 확보**한 뒤 **챕터 정보(배지), 메인 타이틀, 서브 설명문 3단 요소만으로 간결하고 세련되게 구성**합니다 (강사 정보 등 불필요한 요소는 생략하여 높은 가독성과 여백의 미를 구현).

```
[표지 슬라이드 레이아웃 구조 (13.333" x 7.500")]
0.8"                                                  13.333"
 ┌───────────────────────────────────────────────────────────┐
 │ [PART 11 · 심층 강화학습]  y 0.60" (배지, h 0.42", 13pt)    │
 │                                                           │
 │ 신경망과 Q 러닝            y 1.22" (메인 타이틀, 38pt Bold)│
 │                                                           │
 │ 테이블의 한계를 넘어 무한한 상태 공간으로 확장하는...     │
 │ 인공신경망 기반 Q-러닝 원리와 실전 구현                   │
 │ (서브 설명: y 1.98", 폭 7.5", 19pt Regular, #4B5563)      │
 │                                 ┌─────────────────────────┤ y 1.16"
 │                                 │ [커버 이미지 우하단 고정]│
 │                                 │ x 2.06", y 1.16"        │
 │                                 │ 폭 11.27", 높이 6.34"   │
 │                                 │ (84.5% 축소, 16:9 비율) │
 └─────────────────────────────────┴─────────────────────────┘ y 7.50"
```

### 2.1 커버 이미지 파일 탐색 및 우하단 고정 배치 원칙 (Base Layer)
- **파일 위치 및 명명 규칙**:
  - `slides.md`가 위치한 **동일한 폴더** 내에서 해당 챕터/서브챕터의 대표 16:9 커버 이미지 PNG 파일을 자동 탐색합니다.
  - 탐색 우선순위:
    1. `<현재_폴더명>.png` (예: `11_신경망과_Q_러닝.png`, `11_1_DeZero_기초.png` 등)
    2. 디렉토리 내 존재하는 대표 16:9 커버 PNG 파일
- **우하단 고정 배치 (Right-Bottom Anchoring)**:
  - 원본 16:9 커버 이미지를 약 **84.5% (배율 0.845)** 크기로 축소하여 **오른쪽 하단에 밀착 고정**합니다:
    - `img_width = Inches(11.27)` (또는 `SLIDE_WIDTH * 0.845`)
    - `img_height = Inches(6.34)` (또는 `SLIDE_HEIGHT * 0.845`)
    - `left = Inches(2.06)` (또는 `SLIDE_WIDTH - img_width`)
    - `top = Inches(1.16)` (또는 `SLIDE_HEIGHT - img_height`)
  - 슬라이드 캔버스의 배경색이 순백색(`#FFFFFF`)이므로, 순백색 배경을 가진 커버 이미지가 우하단에 배치되면서 좌상단 영역에 넓고 시원한 여백이 자동으로 확보됩니다.

### 2.2 상위 레이어: 3대 핵심 텍스트 배치 규격 (Top Layer)
표지 슬라이드는 **챕터 정보(배지), 메인 타이틀, 서브 설명문 3개 요소만으로 구성**하며, 일러스트와 텍스트가 서로 시각적으로 간섭하지 않도록 여유 있게 배치합니다:

- **1) 챕터 정보 배지 (Chapter Info Badge)**:
  - **위치 및 크기**: `x = Inches(0.8)`, `y = Inches(0.60)`, 너비 `2.6 inch`, 높이 `0.42 inch`
  - **도형 유형**: 모서리가 둥근 직사각형 (`MSO_SHAPE.ROUNDED_RECTANGLE`), 조정값 `0.5` (알약 모양)
  - **색상 및 폰트**: 배경 채우기 브랜드 블루 (`#1A73E8` 또는 `#2563EB`), 외곽선 없음/동일, 흰색 글씨 **`13pt Bold`**, 가운데 정렬
  - **텍스트 내용 예시**: `PART 11 · 심층 강화학습`, `PART 03 · 밴디트 문제` 등

- **2) 메인 타이틀 (Main Title Textbox)**:
  - **위치 및 크기**: `x = Inches(0.8)`, `y = Inches(1.22)`, 너비 `7.0 inch`, 높이 `0.65 inch`
  - **타이포그래피**: **`38pt Bold`**, 텍스트 색상 다크 차콜 (`#1E293B` 또는 `#111827`), 왼쪽 정렬, 단일 행
  - **텍스트 형식 예시**: `신경망과 Q 러닝`

- **3) 서브 설명문 (Subtitle Textbox)**:
  - **위치 및 크기**: `x = Inches(0.8)`, `y = Inches(1.98)`, 너비 `7.5 inch`, 높이 `1.10 inch`
  - **타이포그래피**: **`19pt Regular`**, 텍스트 색상 미디엄 다크 그레이 (`#4B5563`), 줄 간격 `135~140%`, 왼쪽 정렬
  - **텍스트 내용**: 해당 챕터의 핵심 목표 및 학습 의의를 2줄로 시원하게 배치
  - **구성 원칙**: 강사/조교 정보 등은 생략하여 시각적 복잡도를 없애고 여백을 극대화합니다.

### 2.3 표지 슬라이드 노트 (Lecture Script)
- 해당 챕터/서브챕터의 전체 학습 목표와 동기부여를 다루는 50대 정교수 강의 대본(TTS 발음 최적화 구술문)을 `slide.notes_slide`에 필수 삽입합니다.

## 3. 본문 슬라이드 정밀 레이아웃 규격 (Body Slide Layout)

모든 본문 슬라이드는 **동일한 위치의 고정 헤더 영역**과 **좌우 2단 분할의 본문 영역**으로 구성되며, 최상의 가독성과 세련된 타이포그래피를 구현합니다.

```
[본문 슬라이드 레이아웃 구조 (13.333" x 7.500")]
0.8"                                                           12.533"
 ┌───────────────────────────────────────────────────────────────┐
 │ 제목: x 0.8, y 0.4, 32pt Bold              페이지 번호: x 11.33│ 0.4"
 │ 부제: x 0.8, y 1.05, 20pt 회색             y 0.5, 14pt (02/12)│ 1.05"
 │───────────────────────────────────────────────────────────────│ y 1.7 (1px 실선 #E2E8F0)
 │                                                               │
 │   [이미지 영역 (레이어 맨 뒤)]    [본문 텍스트 영역 (세로 중앙)] │ y 1.90"
 │   x 1.0, y 2.15                   x 6.0, y 1.90               │
 │   바운딩 박스 4.2" x 3.9"         폭 6.4", 높이 4.8"          │
 │   비율 유지 (Fit)                 22pt (줄간격 145%, 문단 20pt)│
 │                                   실제 글머리 기호(•)         │
 │   [캡션 영역: 13pt 확대]          둘째 줄 내어쓰기 정렬       │
 │   이미지 아래 일치 정렬, 13pt                                │
 └───────────────────────────────────────────────────────────────┘ y 6.70"
```

### 3.1 헤더 영역 (Header Zone - 모든 본문 슬라이드 고정)
- **제목 (Title)**: `x = 0.8"`, `y = 0.4"`, 폭 `10.5"`, 높이 `0.55"` / **`32pt Bold`**, 왼쪽 정렬, 한 줄
- **부제 (Subtitle)**: `x = 0.8"`, `y = 1.05"`, 폭 `10.5"`, 높이 `0.45"` / **`20pt Regular`**, 회색 (`#6B7280`), 한 줄
- **페이지 번호 (Page Number)**: 오른쪽 위 `x = 11.33"`, `y = 0.5"`, 폭 `1.2"`, 높이 `0.4"` / **`14pt Bold`**, `"02 / 12"` 형식, 오른쪽 정렬
- **구분선 (Divider Line)**: `y = 1.7"`, 가로 `x = 0.8"` ~ `12.533"` (길이 11.733"), 색상 **`#E2E8F0` (깔끔하고 심플한 옅은 회색)**, 굵기 **`1px (Pt(1.0))`**, 단색 실선 (`add_connector(MSO_CONNECTOR.STRAIGHT)`). 음영이나 3D 효과를 일절 배제하여 모던하고 미니멀한 인상을 유지합니다.

---

### 3.2 본문 영역 (Body Content Zone - y 1.90" ~ 6.70")
이미지 왼쪽, 텍스트 오른쪽의 **엄격한 2단 구성**을 적용합니다:

#### 1) 좌측 이미지 & 캡션 영역
- **이미지 좌표 및 크기**: `x = 1.0"`, `y = 2.15"`, 바운딩 박스 **`4.2 × 3.9 inch`** (비율 유지 Fit).
- **레이어 순서 (Z-Order: 맨 뒤)**: 이미지는 **반드시 레이어의 맨 뒤(Back)**에 배치하여 텍스트 상자나 다른 요소를 절대 가리지 않도록 합니다.
- **캡션 (Caption - 13pt 확대 및 이미지 위치 일치)**:
  - **위치 및 크기**: 이미지 바로 아래 `y = top + dest_h + 0.18"`, 너비는 이미지 너비(`dest_w`)와 정확히 일치.
  - **타이포그래피**: 11pt에서 **`13pt Regular`**로 확대하여 가독성 강화.
  - **정렬**: 이미지와 캡션 위치를 일치시키고 가운데 정렬(`PP_ALIGN.CENTER`)하여 시각적 안정감 부여.

#### 2) 우측 본문 텍스트 영역
- **좌표 및 크기**: `x = 6.0"`, `y = 1.90"`, **폭 `6.4 inch`**, **높이 `4.8 inch`**.
- **세로 중앙 정렬 (Vertical Centering)**: 위쪽 구분선(`y = 1.7"`)과 겹치거나 답답하게 붙지 않도록 **`vertical_anchor = MSO_ANCHOR.MIDDLE`**을 적용하여 가용 영역의 세로 정중앙에 배치.
- **글자 크기 (22pt 유지)**: 대형 강의 화면 및 온라인 수강생을 위해 본문 폰트 크기는 **`22pt`**를 엄격히 유지.
- **줄 간격 및 문단 간격 확대**: **줄 간격 `145%` (`line_spacing = 1.45`)**, **문단 간격 `Pt(20)` (`space_after = Pt(20)`)**으로 넓혀 시원하고 쾌적한 행간·문단간 호흡 제공.
- **실제 글머리 기호(Native Bullet) & 내어쓰기(Hanging Indent) 정렬**:
  - 문자열에 직접 타이핑한 `"• "`를 제거하고, 파워포인트 **실제 글머리 기호(`<a:buChar char="•"/>`)** 및 **브랜드 블루 컬러(`<a:srgbClr val="2563EB"/>`)** 적용.
  - **`marL="342900"` (0.375")**, **`indent="-342900"` (-0.375")**의 Hanging Indent를 적용하여, **줄이 바뀌어도 둘째 줄이 첫 줄의 시작 글자에 맞추어 완벽하게 수직 정렬**되도록 보장 (불릿 아래로 글자가 파고들지 않음).
- **정렬 및 여백 균형**: 이미지 영역과 본문 텍스트 영역 사이의 간격을 약 `0.8" ~ 1.0"`로 고르게 배치하여 슬라이드 전체의 좌우 균형감 극대화.
- **슬라이드 영역 초과 방지 및 자동 분할 원칙**:
  - 텍스트가 슬라이드 작업 영역을 벗어나지 않도록 엄격히 관리하며, 내용이 많은 경우 슬라이드를 분리하고 슬라이드 노트(TTS 스크립트)도 함께 분할 동기화합니다.

## 4. 강의 종료 슬라이드 규격 (Thank You / Closing Slide)

모든 강의 프레젠테이션의 마지막 슬라이드는 **"감사합니다" 인사말로 품격 있게 마무리**합니다.

```
[종료 슬라이드 레이아웃 구조 (13.333" x 7.500")]
0.8"                                                           12.533"
 ┌───────────────────────────────────────────────────────────────┐
 │                                            페이지 번호: x 11.33│ 0.5"
 │                                                               │
 │                 [PART 11 · 심층 강화학습 완강]                │ y 2.2" (배지)
 │                                                               │
 │                           감사합니다                          │ y 2.9" (46pt Bold)
 │                                                               │
 │      Q-러닝과 신경망의 결합으로 심층 강화학습의 기초를 완성... │ y 4.05" (18pt)
 │                                                               │
 │                     질의응답(Q&A) 및 토론                     │ y 5.1" (15pt Bold)
 └───────────────────────────────────────────────────────────────┘
```

- **슬라이드 구성 요소**:
  1. **완강 배지 (Completion Badge)**: `x = 5.166"`, `y = 2.2"`, 폭 `3.0"`, 높이 `0.44"`, 알약 모양 파란색 배지, 흰색 `13pt Bold`.
  2. **메인 감사 메시지 (Main Closing Title)**: `x = 2.0"`, `y = 2.9"`, 폭 `9.333"`, 높이 `1.0"`, **`46pt Bold`**, 다크 차콜 (`#1E293B`), 가운데 정렬, **`감사합니다`**.

### 3.3 코드 블록 영역 규격: 와이드 터미널 박스 및 들여쓰기 보존 규칙

> **[코드 블록 레이아웃 원칙: 11.733" 와이드스크린 전체 활용 + 내용 잘림(Clipping) 원천 방지]**  
> 파이썬 코드 블록은 작은 폭(6.0" 등)으로 임의 축소하여 주석이나 코드가 오른쪽 테두리에 잘려나가는 일이 없도록, **슬라이드의 가로 작업 영역 전체(Wide Dark Terminal Box, 폭 11.733", 좌우 마진 각 0.8")를 필수 활용**합니다.

- **와이드 터미널 박스 치수 및 레이아웃 구조**:
  - **기본 와이드 배치 (상단 안내 텍스트 유무에 따른 동적 배치)**:
    - 상단 안내/설명문이 있는 경우:
      - 상단 안내 텍스트: `x = 0.8"`, `y = 1.78"`, `폭 11.733"`, 높이 `0.38" ~ 0.55"` (18pt / 16.5pt, 본문 다크 차콜 `#1F2937`)
      - 터미널 박스: `x = 0.8"`, `y = 2.25" ~ 2.45"`, **`폭 11.733"`**, **`높이 4.55" ~ 4.75"`**
    - 상단 안내 텍스트가 없는 경우:
      - 터미널 박스: `x = 0.8"`, `y = 1.95"`, **`폭 11.733"`**, **`높이 5.05"`**
  - **다크 테마 스타일링**:
    - 배경 채우기: 순수 다크 차콜 (`#111827`, Dark Terminal Background)
    - 테두리선: 미세 테두리선 (`#374151`, 1.0pt)
    - 내부 안쪽 여백: 좌우 `0.40 inch`, 상하 `0.30 inch`
- **코드와 실행 결과(Output) 통합 원칙**:
  - 코드 블록 아래에 수반되는 `**출력 결과**:` 및 출력 텍스트 블록은 별도의 우측 칼럼으로 분리하거나 텍스트 프레임에 어색하게 띄우지 않고, **터미널 내부 하단에 `# --- [실행 결과] ---` 주석 헤더 및 `# 결과내용` 형태로 통합 렌더링**합니다.
  - 실행 결과 헤더는 밝은 연파랑 (`#60A5FA`, Bold), 일반 주석은 부드러운 회색 (`#9CA3AF`), 코드는 순백색 (`#FFFFFF`)으로 색상을 차등 적용하여 개발자 IDE와 동일한 고품격 시각적 위계를 구축합니다.
- **장문 코드(26줄 초과)의 터미널 내부 2단(Two Columns) 분할 렌더링**:
  - 소스코드 줄 수가 26줄을 초과하는 긴 스크립트(예: 35~48줄의 전체 구현 파일)는 단일 컬럼으로 배치 시 슬라이드 하단 밖으로 이탈하거나 폰트 크기가 급락하는 문제가 발생합니다.
  - 따라서 26줄 초과 시 터미널 내부를 **좌/우 2단(Left col 5.2", Right col 5.2", 간격 0.5")**으로 분할하여:
    - 좌측 칼럼: 1번 라인 ~ N/2번 라인
    - 우측 칼럼: N/2+1번 라인 ~ N번 라인
    - 폰트 크기: **`Consolas 10.5pt` ~ `9.5pt`**, 줄 간격 1.25 적용
    - 이를 통해 48줄의 전체 스크립트도 텍스트 잘림 및 세로 이탈 없이 완벽하게 한눈에 조망할 수 있습니다.
- **코드 텍스트 및 들여쓰기(Indentation) 보존 3대 기술 원칙**:
  1. **고정폭(Monospace) 코딩 폰트 의무 적용 (`Consolas`)**:
     - 가변폭 폰트는 스페이스(` `)의 폭이 글자의 20~25%로 극단적으로 좁아 들여쓰기가 납작하게 뭉개집니다.
     - 반드시 고정폭 폰트인 **`Consolas`**를 적용하여 공백 4칸(`    `)이 영문 4글자와 완벽히 동일한 폭을 갖도록 보장합니다.
  2. **선행 공백의 유니코드 불분절 공백(`\u00A0`, Non-Breaking Space) 변환**:
     - 파워포인트 텍스트 프레임 렌더러가 선행 공백을 자동 압축(Collapse)하거나 공백에서 임의 줄바꿈하는 결함을 방지합니다.
     - 각 줄의 시작 부분에 위치한 모든 들여쓰기 공백을 `\u00A0`으로 변환하여, 클래스/함수/조건문의 4칸·8칸 들여쓰기 계층 구조를 100% 보존합니다.
  3. **OpenXML `xml:space="preserve"` 속성 명시적 주입**:
     - OpenXML 표준(ECMA-376)에 따라 `<a:t>` 텍스트 엘리먼트에 `xml:space="preserve"` 속성을 강제 주입하여 파워포인트 엔진이 공백을 일절 손실하지 않도록 합니다.
- **폰트 크기 및 줄 간격 (단일 컬럼 기준)**:
  - 1~12줄: **`Pt(13.5)`**, 줄 간격 1.30
  - 13~18줄: **`Pt(12.0)`**, 줄 간격 1.25
  - 19~26줄: **`Pt(11.0)`**, 줄 간격 1.20
  - 텍스트 래핑: `word_wrap = False` (인위적인 줄바꿈 차단)

### 3.4 코드 분할(Code Chunking) 및 강의 스크립트 분할 동기화 절대 원칙

> **[코드 및 스크립트 분할 원칙: 15줄 초과 코드 우겨넣기 절대 금지]**  
> 긴 소스코드를 폰트만 9pt 이하로 줄여 한 슬라이드에 모두 담는 것은 가독성을 완전히 파괴합니다. 소스코드가 12~15줄을 초과하는 경우 **반드시 논리적 기능 단위로 여러 슬라이드로 분리**하고, **강의 스크립트(Notes)도 각 슬라이드의 코드에 맞춰 함께 분할**해야 합니다.

1. **논리적 분할 기준**:
   - `__init__`, `get_action`, `update` 등의 메서드 단위 분리.
   - 긴 메서드(예: `update`)는 기능적 단계로 분리:
     - **Part 1 (1/2)**: 입력 인자 및 경험 버퍼(`deque`) 저장, 데이터 충족 여부 조기 반환(`if len(memory) < 2: return`), 종단 상태 판정.
     - **Part 2 (2/2)**: 중요도 샘플링 가중치 $\rho$ 계산, TD 목표치 도출 및 $Q$ 테이블 갱신, 정책 비대칭 개선.
   - 슬라이드 부제에 `(1/2)`, `(2/2)` 명시.
2. **강의 스크립트(Slide Notes) 분할 동기화**:
   - 분할된 각 슬라이드에는 해당 코드 스니펫의 원리와 역할을 50초 내외로 구체적으로 설명하는 고품질 교수님 강의 스크립트를 독립적으로 작성하여 슬라이드 노트에 삽입.
   - 앞선 슬라이드와 자연스럽게 연결되면서도 해당 슬라이드의 코드를 한 줄씩 짚어주는 구술 스크립트 제공.

### 3.5 텍스트 과다 슬라이드의 다중 슬라이드 분할 원칙 (Text Overflow Splitting)

> **[텍스트 오버플로우 방지 원칙: 슬라이드 편집 영역 이탈 원천 차단]**  
> 슬라이드 본문 텍스트가 많아 슬라이드 편집 하단 한계선(`y = 6.4"`)을 벗어나는 경우, 폰트를 임의로 줄이지 않고 **반드시 2개 이상의 슬라이드로 분할(`(1/2)`, `(2/2)`)**하여 작성합니다.

- **슬라이드당 적정 텍스트 분량**:
  - 글머리 기호(Bullet): **최대 4 ~ 5개 이내**.
  - 전체 본문 글자 수: **250 ~ 300자 이내** (22pt, 줄 간격 150% 기준 `y = 2.0" ~ 6.4"` 영역에 안락하게 수용).
- **분할 작성 방법**:
  - 소주제 또는 논리적 순서에 따라 본문 단락을 전반부/후반부로 분할.
  - 슬라이드 제목/부제에 `(1/2)`, `(2/2)`를 부기하여 청중과 강사가 연속된 맥락임을 인지하도록 구성.
  - 슬라이드 노트(강의 스크립트) 역시 각 슬라이드 분량에 맞추어 분할 작성.

## 4. 슬라이드 본문 수식 및 타이포그래피 변환 엔진 (LaTeX / HTML / Markdown → Clean Unicode)

> **[수식 및 마크다운 변환 절대 원칙: 원화 기호(₩), 백슬래시(\), raw HTML 및 마크다운 기호 완전 박멸]**  
> 윈도우 환경 및 한국어 폰트(맑은 고딕, 나눔고딕 등)에서 백슬래시(`\`)는 원화 기호(`₩`)로 강제 매핑되어 화면에 `₩varepsilon(10%)`, `₩rho`, `₩gamma`와 같은 흉측한 코드로 노출됩니다. 또한 마크다운 강조 기호(`*`, `**`, `` ` ``)나 HTML 태그(`<sup>`, `<sub>`, `<b>`)가 슬라이드 본문에 날것으로 노출되면 가독성을 심각하게 해칩니다.  
> 따라서 슬라이드 본문 렌더링 시 **모든 LaTeX 문법, HTML 태그, 마크다운 기호는 100% 예외 없이 미려한 유니코드 수학 기호 및 일반 텍스트로 완전 변환**되어야 합니다.

1. **위첨자(Superscript) 및 아래첨자(Subscript) 정밀 유니코드 매핑**:
   - HTML `<sup>...</sup>`, `<sub>...</sub>` 및 LaTeX `^{...}`, `_{...}`, `^c`, `_c`를 완벽한 유니코드 특수문자로 치환:
     - 위첨자: `0~9` $\to$ `⁰~⁹`, `+` $\to$ `⁺`, `-` $\to$ `⁻`, `=` $\to$ `⁼`, `()` $\to$ `⁽⁾`, `n` $\to$ `ⁿ`, `i` $\to$ `ⁱ`, `T` $\to$ `ᵀ`, `N` $\to$ `ᴺ`, `x` $\to$ `ˣ`, `y` $\to$ `ʸ`
       - 예시: `*y* = 3*x*<sup>2</sup>` $\to$ **`y = 3x²`**, `(y - t)^2` $\to$ **`(y - t)²`**, `<sup>*N*</sup>` $\to$ **`ᴺ`**
     - 아래첨자: `0~9` $\to$ `₀~₉`, `+` $\to$ `₊`, `-` $\to$ `₋`, `=` $\to$ `₌`, `()` $\to$ `₍₎`, `a` $\to$ `ₐ`, `e` $\to$ `ₑ`, `h` $\to$ `ₕ`, `i` $\to$ `ᵢ`, `j` $\to$ `ⱼ`, `k` $\to$ `ₖ`, `l` $\to$ `ₗ`, `m` $\to$ `ₘ`, `n` $\to$ `ₙ`, `o` $\to$ `ₒ`, `p` $\to$ `ₚ`, `r` $\to$ `ᵣ`, `s` $\to$ `ₛ`, `t` $\to$ `ₜ`, `u` $\to$ `ᵤ`, `v` $\to$ `ᵥ`, `x` $\to$ `ₓ`
       - 예시: `<sub>*t*</sub>` $\to$ **`ₜ`**, `R_{t+1}` $\to$ **`Rₜ₊₁`**, `S_{t+1}` $\to$ **`Sₜ₊₁`**, `y_1` $\to$ **`y₁`**, `W_1` $\to$ **`W₁`**, `b_1` $\to$ **`b₁`**, `\max_a` $\to$ **`maxₐ`**
2. **HTML 태그 완전 박멸 및 언래핑 (Unwrapping)**:
   - 메타데이터 태그 제거: `<div align=.*?>.*?</div>` 완전 삭제
   - 서식 태그 언래핑: `<b>`, `<strong>`, `<i>`, `<em>`, `<code>`, `<span>`, `<p>`, `<br>` 태그를 제거하고 내부 텍스트만 보존
3. **마크다운 서식(Emphasis & Code)의 클린 텍스트 변환**:
   - 인라인 코드: `` `y.backward()` `` $\to$ **`y.backward()`**, `` `Variable` `` $\to$ **`Variable`** (백슬래시나 백틱 없는 깔끔한 식별자 표기)
   - 변수 이탤릭 및 볼드:
     - `*y*` $\to$ **`y`**, `*x*` $\to$ **`x`**, `*w*` $\to$ **`w`**, `*b*` $\to$ **`b`**
     - `3*x*` $\to$ **`3x`**
     - `**d*y* / d*x* = 6*x***` $\to$ **`dy / dx = 6x`** (중첩된 볼드/이탤릭 기호 완전 정제)
     - `**출력 결과**:` $\to$ **`출력 결과:`**
4. **LaTeX 특수 그리스 문자 및 연산자 매핑**:
   - `\varepsilon`, `\epsilon` $\to$ **`ε`** (특히 `\varepsilon(10%)` $\to$ `ε(10%)` 필수 변환)
   - `\rho` $\to$ **`ρ`**, `\gamma` $\to$ **`γ`**, `\alpha` $\to$ **`α`**, `\delta` $\to$ **`δ`**, `\theta` $\to$ **`θ`**, `\sigma` $\to$ **`σ`**, `\pi` $\to$ **`π`**, `\eta` $\to$ **`η`**, `\nabla` $\to$ **`∇`**, `\partial` $\to$ **`∂`**
   - `\sum` $\to$ **`∑`**, `\prod` $\to$ **`∏`**, `\mathbb{E}` / `\mathbb E` $\to$ **`E`**, `\mathbb{R}` $\to$ **`ℝ`**
   - `\rightarrow`, `\to`, `\xrightarrow{...}` $\to$ **`→`**, `\leftarrow` $\to$ **`←`**, `\implies` $\to$ **`⇒`**
   - `\times` $\to$ **`×`**, `\cdot` $\to$ **`·`**, `\approx` $\to$ **`≈`**, `\le` / `\leq` $\to$ **`≤`**, `\ge` / `\geq` $\to$ **`≥`**, `\neq` $\to$ **`≠`**, `\in` $\to$ **`∈`**, `\sim` $\to$ **`~`**, `\mid` $\to$ **`|`**
   - `\dots`, `\cdots`, `\hellip`, `&hellip;` $\to$ **`…`**
   - `\argmax`, `\arg\max` $\to$ **`argmax`**
5. **복합 수식 문법 언래핑 (Unwrapping)**:
   - 분수: `\frac{A}{B}` $\to$ **`(A) / (B)`** 또는 **`A / B`** (중첩 중괄호 `{t+1}` 대응 스택 기반 언래핑)
   - 크기 조절 괄호: `\left(`, `\right)`, `\left[`, `\right]`, `\left\{`, `\right\}` $\to$ **`(`, `)`, `[`, `]`, `{`, `}`**
   - 텍스트/서체 태그: `\text{...}`, `\mathbf{...}`, `\operatorname{...}` $\to$ **내부 내용만 추출**
   - 수식 구분자 제거: `$$...$$` 및 `$..$` 완전 제거
6. **최종 안전망 (Sanitization Pass)**:
   - 위 변환을 거친 후 남아 있는 모든 `\word` 형태의 잔여 LaTeX 명령어(`re.sub(r"\\[a-zA-Z]+", "", text)`)와 **모든 백슬래시 문자(`\`)를 100% 제거**하여 원화 기호(`₩`)가 단 1개도 노출되지 않도록 보장합니다.

## 5. 슬라이드 노트(강의 스크립트)의 TTS 음성 발음 최적화 표준

슬라이드 노트(Notes Page)는 **향후 음성 합성(TTS) 엔진으로 낭독될 강의 스크립트**이므로, 수식 코드가 아닌 **자연스러운 한국어 구술 독음 표준**으로 100% 변환하여 삽입합니다:

| 원본 수식/코드 기호 | TTS 음성 구술 표준 텍스트 | 자연스러운 발음 예시 |
| :--- | :--- | :--- |

## 6. `python-pptx` 표준 구현 코드 스펙

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN, MSO_ANCHOR
from pptx.enum.shapes import MSO_CONNECTOR, MSO_SHAPE

prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.500)

FONT_NAME = "나눔고딕" # 또는 "맑은 고딕", "Pretendard"
COLOR_TITLE = RGBColor(17, 24, 39)    # #111827 (거의 검정)
COLOR_SUBTITLE = RGBColor(107, 114, 128) # #6B7280 (회색)
COLOR_BODY = RGBColor(31, 41, 55)     # #1F2937
COLOR_DIVIDER = RGBColor(156, 163, 175) # #9CA3AF (실선)
COLOR_BRAND = RGBColor(26, 115, 232)  # #1A73E8 (배지)

# ==========================================
# 0. 표지 슬라이드 생성 (16:9 커버 이미지 바탕 + 상위 레이어 편집 가능 타이포그래피)
# ==========================================
def create_editable_cover_slide(prs, cover_png_path, badge_text, title_text, subtitle_text, script_text=""):
    slide = prs.slides.add_slide(prs.slide_layouts[6])

    # 1. 하위 레이어 (Base Layer): 16:9 와이드스크린 커버 이미지 삽입
    if os.path.exists(cover_png_path):
        slide.shapes.add_picture(cover_png_path, Inches(0), Inches(0), width=Inches(13.333), height=Inches(7.500))

    # 2. 상위 레이어 (Top Layer): 배지 (파란 알약 모양, 14pt Bold)
    badge = slide.shapes.add_shape(
        MSO_SHAPE.ROUNDED_RECTANGLE, Inches(0.8), Inches(1.0), Inches(3.0), Inches(0.5)
    )
    badge.fill.solid()
    badge.fill.fore_color.rgb = COLOR_BRAND
    badge.line.color.rgb = COLOR_BRAND
    badge.adjustments[0] = 0.5

    tf = badge.text_frame
    tf.word_wrap = False
    p = tf.paragraphs[0]
    p.text = badge_text
    p.font.name = FONT_NAME
    p.font.size = Pt(14)
    p.font.bold = True
    p.font.color.rgb = RGBColor(255, 255, 255)
    p.alignment = PP_ALIGN.CENTER

    # 3. 상위 레이어: 메인 강의 제목 (44pt Bold, 100% 편집 가능 텍스트)
    title_box = slide.shapes.add_textbox(Inches(0.8), Inches(1.75), Inches(5.8), Inches(1.5))
    tf = title_box.text_frame
    tf.word_wrap = True
    p = tf.paragraphs[0]
    p.text = title_text
    p.font.name = FONT_NAME
    p.font.size = Pt(44)
    p.font.bold = True
    p.font.color.rgb = COLOR_TITLE

    # 4. 상위 레이어: 부제목 설명문 (20pt, 100% 편집 가능 텍스트)
    sub_box = slide.shapes.add_textbox(Inches(0.8), Inches(3.45), Inches(5.8), Inches(1.8))
    tf = sub_box.text_frame
    tf.word_wrap = True
    p = tf.paragraphs[0]
    p.text = subtitle_text
    p.font.name = FONT_NAME
    p.font.size = Pt(20)
    p.font.color.rgb = COLOR_SUBTITLE

    p2 = tf.add_paragraph()
    p2.text = "\n강의: 이호진 교수 · 조교 지니와 도로시 탐험대"
    p2.font.name = FONT_NAME
    p2.font.size = Pt(16)
    p2.font.bold = True
    p2.font.color.rgb = RGBColor(55, 65, 81)

    # 5. 슬라이드 노트 (TTS 최적화 구술문)
    if script_text:
        notes_slide = slide.notes_slide
        notes_slide.notes_text_frame.text = script_text.strip()

# ==========================================
# 1. 헤더 영역 생성 (모든 본문 슬라이드 동일 적용)
# ==========================================
def add_header(slide, title_text, subtitle_text, page_str):
    # 제목: x 0.8, y 0.4, 32pt Bold, 왼쪽 정렬, 한 줄
    t_box = slide.shapes.add_textbox(Inches(0.8), Inches(0.4), Inches(10.5), Inches(0.55))
    tf = t_box.text_frame
    tf.word_wrap = True
    p = tf.paragraphs[0]
    p.text = title_text
    p.font.name = FONT_NAME
    p.font.size = Pt(32)
    p.font.bold = True
    p.font.color.rgb = COLOR_TITLE

    # 부제: x 0.8, y 1.05, 20pt 회색, 한 줄
    s_box = slide.shapes.add_textbox(Inches(0.8), Inches(1.05), Inches(10.5), Inches(0.45))
    sf = s_box.text_frame
    sf.word_wrap = True
    sp = sf.paragraphs[0]
    sp.text = subtitle_text
    sp.font.name = FONT_NAME
    sp.font.size = Pt(20)
    sp.font.color.rgb = COLOR_SUBTITLE

    # 페이지 번호: 오른쪽 위 x 11.33, y 0.5, 14pt ("02 / 54")
    num_box = slide.shapes.add_textbox(Inches(11.333), Inches(0.5), Inches(1.2), Inches(0.4))
    np_p = num_box.text_frame.paragraphs[0]
    np_p.text = page_str
    np_p.font.name = FONT_NAME
    np_p.font.size = Pt(14)
    np_p.font.color.rgb = COLOR_DIVIDER
    np_p.alignment = PP_ALIGN.RIGHT

    # 구분선: y 1.7, 가로 x 0.8 ~ 12.53, 색 #9CA3AF, 굵기 0.75pt(1px)
    line = slide.shapes.add_connector(
        MSO_CONNECTOR.STRAIGHT, Inches(0.8), Inches(1.7), Inches(12.533), Inches(1.7)
    )
    line.line.color.rgb = COLOR_DIVIDER
    line.line.width = Pt(0.75)

# ==========================================
# 2. 본문 영역 생성 (2단 구성: 이미지 좌, 텍스트 우)
# ==========================================
def add_body_2column(slide, image_path, caption_text, body_text):
    # 이미지: x 1.0, y 2.0, 4.4 x 4.4inch 정사각형 비율 유지
    if image_path:
        slide.shapes.add_picture(image_path, Inches(1.0), Inches(2.0), width=Inches(4.4))

    # 캡션: 이미지 아래 y 6.4, 11pt, 가운데 정렬
    if caption_text:
        c_box = slide.shapes.add_textbox(Inches(1.0), Inches(6.4), Inches(4.4), Inches(0.5))
        cp = c_box.text_frame.paragraphs[0]
        cp.text = caption_text
        cp.font.name = FONT_NAME
        cp.font.size = Pt(11)
        cp.font.color.rgb = RGBColor(75, 85, 99)
        cp.alignment = PP_ALIGN.CENTER

    # 본문 텍스트: x 6.6, y 2.0, 폭 5.9inch, 22pt, 줄 간격 150%, 상하 가운데 정렬
    t_box = slide.shapes.add_textbox(Inches(6.6), Inches(2.0), Inches(5.9), Inches(4.4))
    tf = t_box.text_frame
    tf.word_wrap = True
    tf.vertical_anchor = MSO_ANCHOR.MIDDLE
    tp = tf.paragraphs[0]
    tp.text = body_text
    tp.font.name = FONT_NAME
    tp.font.size = Pt(22)
    tp.font.color.rgb = COLOR_BODY
    tp.line_spacing = 1.5

# ==========================================
# 3. 코드 블록 생성 (와이드 다크 터미널 박스 + 완벽한 들여쓰기)
# ==========================================
def add_code_wide_box(slide, code_text, left=Inches(0.8), top=Inches(2.0), width=Inches(11.733), height=Inches(4.9)):
    # 다크 차콜 와이드 터미널 배경 박스
    box = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, left, top, width, height)
    box.fill.solid()
    box.fill.fore_color.rgb = RGBColor(17, 24, 39) # #111827
    box.line.color.rgb = RGBColor(55, 65, 81)      # #374151
    box.line.width = Pt(1)
    
    # 흰색 코드 텍스트 (Consolas 고정폭 + \u00A0 들여쓰기)
    tf = box.text_frame
    tf.word_wrap = False
    tf.margin_left = Inches(0.4)
    tf.margin_top = Inches(0.3)
    tf.margin_right = Inches(0.4)
    tf.margin_bottom = Inches(0.3)
    
    for i, line in enumerate(code_text.rstrip().split("\n")):
        p = tf.paragraphs[0] if i == 0 else tf.add_paragraph()
        leading_spaces = len(line) - len(line.lstrip(" "))
        preserved_line = ("\u00A0" * leading_spaces) + line.lstrip(" ")
        p.text = preserved_line
        p.font.name = "Consolas"
        p.font.size = Pt(13)
        p.font.color.rgb = RGBColor(255, 255, 255) # 흰색
        p.line_spacing = 1.25

        # OpenXML xml:space="preserve" 주입
        for r in p._p.xpath(".//a:t"):
            r.set("{http://www.w3.org/XML/1998/namespace}space", "preserve")
```
