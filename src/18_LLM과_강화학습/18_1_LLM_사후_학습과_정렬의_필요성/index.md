> 앵무새에게 사용자의 마음을 헤아려 질문에 친절하고 정직하게 답변하는 태도를 가르치는 과정, 이것이 바로 **사후 학습(Post-training)과 정렬(Alignment)**입니다.

## 17.1.1 사전 학습(Pre-training) 모델의 한계

현대 대형언어모델(LLM)의 생애 주기는 크게 두 단계로 나뉩니다:

```
[ 인터넷 원시 텍스트 수조 개 ] ───> [ 1단계: 사전 학습 (Pre-training) ] ───> [ 기본 모델 (Base LLM) ]
                                                                                   │
                                                                                   ▼
[ 인간 지시 데이터 & 피드백 ] ───> [ 2단계: 사후 학습 (Post-training) ] ───> [ 정렬된 모델 (Aligned LLM) ]
```

### 1) 기본 모델(Base LLM)의 학습 목표
- 기본 모델은 오직 하나의 목적 함수로 훈련됩니다:
  $$
  \mathcal{L}_{\text{pretrain}}(\theta) = -\sum_{t=1}^T \log P_\theta(x_t \mid x_1, x_2, \dots, x_{t-1})
  $$
- 즉, 앞선 단어들이 주어졌을 때 **"다음에 올 가장 확률이 높은 단어(Next Token)"**를 맞추는 자기지도 학습(Self-Supervised Learning)입니다.

### 2) 왜 Base 모델만으로는 대화형 비서가 될 수 없는가?
- **질문과 답변의 불일치**: "파이썬으로 퀵소트를 구현해 줘"라는 프롬프트를 주면, 사용자의 요구를 들어주는 것이 아니라 인터넷 시험 문제지의 다음 줄처럼 "2번 문제: 머지소트를 구현하시오"를 이어서 써버립니다.
- **환각(Hallucination)**: 그럴듯해 보이지만 완전히 거짓인 사실을 확신에 차서 지어냅니다.
- **유해성 및 편향(Toxicity & Bias)**: 인터넷 웹 문서에 포함된 인종차별, 성차별, 욕설 및 위험한 범죄 지침(해킹, 폭탄 제조 등)을 필터링 없이 그대로 출력합니다.

## 17.1.2 사후 학습(Post-training)의 2단계 구조

이를 극복하기 위해 Anthropic과 OpenAI는 사전 학습 이후 모델의 태도를 교정하는 **사후 학습(Post-training)**을 도입했습니다:

### 1단계: 지도학습 미세조정 (SFT: Supervised Fine-Tuning)
- 전문가들이 직접 작성한 고품질의 지시-응답 쌍 $(x, y)$ 수만 건을 모델에게 교과서처럼 가르칩니다:
  $$
  \mathcal{L}_{\text{SFT}}(\theta) = -\sum_{(x, y) \in \mathcal{D}_{\text{SFT}}} \sum_{t=1}^{|y|} \log P_\theta(y_t \mid x, y_{<t})
  $$
- 이 단계를 거치면 모델은 비로소 "질문을 받으면 답변을 해야 한다"는 대화 인터페이스의 기본 양식을 습득합니다.

### 2단계: 강화학습 정렬 (RL Alignment: RLHF / DPO / GRPO)
- 하지만 SFT만으로는 한계가 명확합니다:
  1. **모호한 정답의 문제**: "창의적인 시를 써줘", "이 코드를 더 깔끔하게 리팩토링해 줘" 같은 작업에는 단 하나의 유일한 정답(Ground-truth label)이 존재하지 않습니다.
  2. **노출 편향(Exposure Bias)**: 학습 시에는 교사의 완벽한 앞선 토큰들을 보고 다음 토큰을 맞췄지만, 실제 추론 시에는 자신이 생성한 불완전한 토큰들을 딛고 가야 하므로 사소한 실수가 눈덩이처럼 불어납니다.
  3. **선호도 비교의 우수성**: 사람은 완벽한 에세이를 처음부터 직접 쓰기는 어렵지만, AI가 쓴 두 개의 글을 보고 **"A 글이 B 글보다 논리적이고 유익하다"고 순위를 매기는 것(Ranking)**은 훨씬 쉽고 정확합니다.

강화학습은 바로 이러한 **"인간의 선호도 랭킹"을 보상 신호로 삼아 모델의 생성 정책 $\pi_\theta$ 전체를 단어 단위가 아닌 전체 문장 단위로 최적화**합니다!

## 17.1.3 AI 정렬의 3대 핵심 원칙 (The 3H Principles)

Anthropic의 연구진(Askell et al., 2021)은 성공적인 정렬이 지향해야 할 3대 표준을 정립했습니다:

| 원칙 | 영문 명칭 | 정의 및 모델의 행동 지침 |
| :--- | :--- | :--- |
| **유용성** | **Helpful** | • 사용자의 지시와 의도를 정확히 파악하여 실질적인 도움과 가치를 제공해야 한다.<br>• 필요한 정보를 명확하고 군더더기 없이 풍부하게 제시한다. |
| **진실성** | **Honest** | • 거짓된 정보를 날조(환각)하지 않고, 모르는 것은 "모른다"고 솔직히 인정해야 한다.<br>• 자신의 지식 한계와 불확실성을 사용자에게 정직하게 밝힌다. |
| **무해성** | **Harmless** | • 폭력, 범죄, 자해, 혐오 발언 등 인간에게 신체적·정신적·사회적 해악을 끼치는 출력을 단호히 거부해야 한다.<br>• 악의적 탈옥(Jailbreak) 프롬프트에 면역력을 갖춘다. |

이 3H 원칙은 단순한 프롬프트 엔지니어링으로는 달성할 수 없으며, **보상 모델링과 정밀한 강화학습 정책 최적화**를 통해 신경망의 깊은 파라미터 내부에 확고한 가치관으로 내재화되어야 합니다.
