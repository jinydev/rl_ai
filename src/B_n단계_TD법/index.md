# APPENDIX B: n단계 TD법 (n-step Temporal Difference)

**그림 B-0** 한 걸음 전진 대신 세 걸음(n-step)을 한꺼번에 껑충 뛰어 발판의 누적 보상을 한 번에 갱신하는 도로시와 지니
![n단계 TD 인트로](./img/jiny_app_b_nstep_td.png)

> 바로 눈앞의 1단계 보상만을 관찰하던 기본 TD법과, 에피소드가 완전히 끝날 때까지 기다려야 했던 몬테카를로법(MC) 사이의 거대한 간극을 잇는 **n단계 TD법**과 **TD(*λ*)**의 원리를 탐구합니다. 편향(Bias)과 분산(Variance) 사이의 황금 타협점을 찾고, 모든 n단계의 통찰을 기하학적으로 통합하는 람다 수익(λ-return)의 수학적 아름다움을 도로시, 지니 조교와 함께 파헤쳐봅시다!

---

## B.1 1단계 TD와 몬테카를로 사이의 스펙트럼

7장에서 배운 1단계 시간차 학습(1-step TD)은 바로 다음 1단계의 실제 보상과 다음 상태 가치 추정치만을 이용하여 즉각적으로 가치를 갱신했습니다:

> *G*<sub>*t*</sub><sup>(1)</sup> = *R*<sub>*t*</sub> + *γ* *V*<sub>*π*</sub>(*S*<sub>*t*+1</sub>)

반면 5장에서 배운 몬테카를로법(MC)은 에피소드가 완전히 끝날 때까지의 모든 미래 보상을 남김없이 더한 전체 수익을 사용했습니다:

> *G*<sub>*t*</sub><sup>(∞)</sup> = *R*<sub>*t*</sub> + *γ* *R*<sub>*t*+1</sub> + *γ*<sup>2</sup> *R*<sub>*t*+2</sub> + ... + *γ*<sup>*T*−*t*</sup> *R*<sub>*T*</sub>

그렇다면 왜 우리는 극단적으로 1단계만 보거나, 아니면 끝까지 다 보아야만 할까요? 2단계, 3단계, 5단계 앞까지만 실제로 경험해보고 그 이후를 가치 함수로 추정하는 '중간 다리'는 없을까요?

이 자연스러운 질문에서 출발한 것이 바로 **n단계 TD법(n-step TD Learning)**입니다.

**그림 B-1** 1단계 TD의 높은 편향과 몬테카를로의 높은 분산 사이에서 가장 낮은 오차를 달성하는 n단계 TD법과 TD(*λ*)의 연속 스펙트럼

## B.2 n단계 수익(n-step Return)과 가치 갱신

*n*단계 TD법에서는 현재 시점 *t*부터 앞으로 *n*스텝 동안 실제로 발생한 보상들을 할인하여 직접 누적하고, *n*번째 도달한 미래 상태 *S*<sub>*t*+*n*</sub>의 가치만을 신경망(또는 테이블) 가치 함수로 부트스트랩합니다.

> ### (식 B.1) n단계 수익 (n-step Return)
> *G*<sub>*t*</sub><sup>(*n*)</sup> = *R*<sub>*t*</sub> + *γ* *R*<sub>*t*+1</sub> + *γ*<sup>2</sup> *R*<sub>*t*+2</sub> + ... + *γ*<sup>*n*−1</sup> *R*<sub>*t*+*n*−1</sub> + *γ*<sup>*n*</sup> *V*<sub>*π*</sub>(*S*<sub>*t*+*n*</sub>)

*n*의 크기에 따라 수익이 어떻게 확장되는지 살펴보겠습니다:
- **1단계 (*n* = 1):** *G*<sub>*t*</sub><sup>(1)</sup> = *R*<sub>*t*</sub> + *γ* *V*<sub>*π*</sub>(*S*<sub>*t*+1</sub>) → **표준 1-step TD**
- **2단계 (*n* = 2):** *G*<sub>*t*</sub><sup>(2)</sup> = *R*<sub>*t*</sub> + *γ* *R*<sub>*t*+1</sub> + *γ*<sup>2</sup> *V*<sub>*π*</sub>(*S*<sub>*t*+2</sub>)
- **3단계 (*n* = 3):** *G*<sub>*t*</sub><sup>(3)</sup> = *R*<sub>*t*</sub> + *γ* *R*<sub>*t*+1</sub> + *γ*<sup>2</sup> *R*<sub>*t*+2</sub> + *γ*<sup>3</sup> *V*<sub>*π*</sub>(*S*<sub>*t*+3</sub>)
- **무한대 (*n* = ∞):** *G*<sub>*t*</sub><sup>(∞)</sup> = *R*<sub>*t*</sub> + *γ* *R*<sub>*t*+1</sub> + *γ*<sup>2</sup> *R*<sub>*t*+2</sub> + ... → **몬테카를로법 (MC)**

이 *n*단계 수익을 목표치(TD Target)로 삼아 가치 함수를 갱신합니다:

> ### (식 B.2) n단계 TD 가치 함수 갱신식
> *V*<sub>*π*</sub>(*S*<sub>*t*</sub>) ← *V*<sub>*π*</sub>(*S*<sub>*t*</sub>) + *α* ( *G*<sub>*t*</sub><sup>(*n*)</sup> − *V*<sub>*π*</sub>(*S*<sub>*t*</sub>) )

### 편향과 분산의 트레이드오프 (Bias-Variance Tradeoff)

- **1단계 TD (*n* = 1):**  
  단 1스텝의 보상만 보므로 확률적 변동(분산)은 매우 작지만, 아직 부정확한 초기 가치 추정치 *V*(*S*<sub>*t*+1</sub>)에 전적으로 의존하므로 **편향(Bias)이 큽니다**.
- **몬테카를로 (*n* = ∞):**  
  가치 함수의 추정치를 전혀 빌려 쓰지 않고 오직 실제 보상만으로 계산하므로 편향은 0(Unbiased)이지만, 수많은 확률적 전이가 누적되어 **분산(Variance)이 극도로 치솟습니다**.
- **최적의 n (*n* = 3 ~ 5):**  
  수많은 실제 실험에서 *n*을 3에서 5 정도로 설정했을 때, 편향과 분산이 절묘하게 상쇄되어 1-step TD나 순수 MC보다 **훨씬 빠르고 안정적으로 참 가치에 수렴**하는 현상이 확인됩니다. (14.3절의 레인보우 DQN에서도 다중 스텝 학습 *n*=3이 필수 요소로 채택된 이유가 바로 여기에 있습니다!)

## B.3 TD(λ): 모든 n단계 수익의 기하학적 통합

그렇다면 현실의 복잡한 문제에서 "최적의 *n*은 3인가, 4인가, 아니면 7인가?"를 두고 끊임없이 고민해야 할까요?  
강화학습의 거장 리처드 서튼(Richard Sutton) 교수는 특정한 *n* 하나만을 편식하지 않고, **모든 *n*단계 수익들을 기하급수적으로 감쇠하는 가중치로 부드럽게 섞어 쓰는 천재적인 아이디어인 TD(*λ*)**를 제안했습니다!

> ### (식 B.3) λ-수익 (The λ-return)
> *G*<sub>*t*</sub><sup>*λ*</sup> = (1 − *λ*) ∑<sub>*n*=1</sub><sup>∞</sup> *λ*<sup>*n*−1</sup> *G*<sub>*t*</sub><sup>(*n*)</sup>  
> = (1 − *λ*) *G*<sub>*t*</sub><sup>(1)</sup> + (1 − *λ*)*λ* *G*<sub>*t*</sub><sup>(2)</sup> + (1 − *λ*)*λ*<sup>2</sup> *G*<sub>*t*</sub><sup>(3)</sup> + ...

여기서 감쇠 계수 *λ*는 0과 1 사이의 실수(0 ≤ *λ* ≤ 1)입니다.  
가중치들의 총합을 무한등비급수 공식으로 계산해 보면 정확하게 **1.0**이 됨을 쉽게 증명할 수 있습니다:

> (1 − *λ*) + (1 − *λ*)*λ* + (1 − *λ*)*λ*<sup>2</sup> + ...  
> = (1 − *λ*) (1 + *λ* + *λ*<sup>2</sup> + ...)  
> = (1 − *λ*) · 1 / (1 − *λ*) = **1**

### 파라미터 *λ*에 따른 거동

- ** *λ* = 0 일 때:**  
  첫 번째 항의 가중치만 (1 − 0) · 0<sup>0</sup> = 1이 되고 나머지 항은 모두 0이 됩니다. 즉, 정확히 **1-step TD**와 일치합니다!
- ** *λ* = 1 일 때:**  
  모든 중간 항들이 소거되고 에피소드 끝의 전체 누적 수익만을 반영하는 **순수 몬테카를로법(MC)**과 정확히 일치합니다!
- ** 0 < *λ* < 1 일 때:**  
  가까운 미래의 TD 수익에는 큰 가중치를, 먼 미래의 수익에는 지수적으로 줄어드는 작은 가중치를 부여하여, 편향과 분산이 가장 완벽하게 조화된 최상의 학습 효율을 발휘합니다.

> [!NOTE]
> **자격 흔적 (Eligibility Traces):**  
> (식 B.3)의 람다 수익은 에피소드가 끝나야만 과거의 모든 *n*단계 수익을 계산할 수 있는 '전방향 관점(Forward View)'입니다.  
> 하지만 놀랍게도 과거에 방문했던 상태들에 감쇠하는 흔적(Trace)을 남겨두는 **자격 흔적(Eligibility Trace, *e*<sub>*t*</sub>(*s*))** 메커니즘을 사용하면, 에피소드 종료를 기다릴 필요 없이 **매 타임스텝마다 즉각적으로 TD(*λ*)와 수학적으로 100% 동일한 갱신**을 수행하는 '후방향 관점(Backward View)'을 구현할 수 있습니다!
