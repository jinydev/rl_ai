- **등장인물**:
  - **도로시(Dorothy)**: 10세 한국계 여아, 양갈래 땋은 머리(twin pigtails), 연청색 멜빵바지('STEM HERO' 패치), 빨간 캔버스 운동화.
  - **이호진 교수님(Professor Hojin)**: 40대 초반 동안의 한국인 컴퓨터공학 교수, 깔끔한 짧은 검은 머리, 얇은 둥근 금속테 안경, 네이비 폴로 셔츠.
  - **지니(Jiny)**: 빛나는 파란 홀로그램 AI 요정.
  - **토토(Toto)**: 똑똑한 브라운 테리어 강아지.
- **장면 구성**:
  - 미래형 AI 신경망 랩.
  - 도로시가 홀로그램 패드 위에 떠오른 2층 신경망 노드(입력 노드 - 빛나는 크리스털 ReLU 활성화 스위치 은닉 노드 - 출력 노드)를 직접 조율.
  - 지니가 비선형 사인 함수 곡선(`y = sin(2*pi*x)`)을 홀로그램으로 투사하여, 활성화 함수가 부여하는 유연한 곡선 근사 능력을 입증.
  - 이호진 교수님이 모듈식 딥러닝 설계도(`Model -> Linear Layers -> Activation (ReLU) -> Optimizer (Adam)`)를 짚으며 체계적인 객체지향 딥러닝 구조를 강의.
  - 토토가 바닥에서 활기차게 꼬리를 흔듦.
- **화풍**: 따뜻하고 화사한 현대적 웹툰/애니메이션 스타일, 정교한 2D/2.5D 일러스트레이션.
