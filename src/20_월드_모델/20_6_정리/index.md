### 1. 20장 월드 모델 핵심 개념 요약

이번 20장에서는 경험을 통해서만 환경을 배우던 모델 프리 강화학습의 한계를 뛰어넘어, 에이전트 내부에 환경의 물리 법칙을 압축한 시뮬레이터를 구축하는 **월드 모델(World Models)**의 전체 이론과 최신 프론티어를 살펴보았습니다.

| 모델 / 기법 | 핵심 아키텍처 및 메커니즘 | 주요 의의 및 대표 성과 |
| :--- | :--- | :--- |
| **World Models (2018)**<br>*(Ha & Schmidhuber)* | • **V (VAE)**: $64\times 64\times 3$ 픽셀을 32차원 잠재 벡터 $z$로 압축<br>• **M (MDN-RNN)**: 혼합 밀도 순환신경망으로 다음 잠재 상태 확률 예측<br>• **C (Linear)**: 진화 전략(CMA-ES)으로 최적화된 초경량 선형 제어기 | • 실제 환경 접근 0회! 오직 "꿈속에서의 상상 롤아웃"만으로 학습 후 CarRacing 만점 완주 |
| **Dreamer (2020~2024)**<br>*(Danijar Hafner et al.)* | • **RSSM**: 결정론적 $h_t$(GRU)와 확률적 $z_t$(Categorical)의 융합<br>• **잠재 상상 롤아웃**: 픽셀 복원 없이 잠재 공간에서 Actor-Critic BPTT 역전파 | • 고정 하이퍼파라미터로 마인크래프트(Minecraft)에서 사전 지식 없이 다이아몬드 자율 채굴 성공 |
| **Genie (2024)**<br>*(Google DeepMind)* | • **ST-Tokenizer**: 시공간 비디오 이산 토큰화<br>• **LAM (잠재 행동 모델)**: 레이블 없는 비디오에서 8가지 잠재 행동 자동 유추<br>• **ST-Transformer**: 11B 파라미터 시공간 인터랙티브 생성기 | • 단 1장의 사진/스케치를 실시간 플레이 가능한 조작형 2D/3D 게임 환경으로 즉시 변환 |
| **NVIDIA Cosmos (2025~2026)**<br>*(NVIDIA Physical AI)* | • **Predict**: 7B/14B DiT 기반의 물리적 엄밀성을 갖춘 미래 시공간 예측<br>• **Transfer**: Isaac Sim 가상 데이터를 실제 센서 노이즈가 반영된 실사로 변환<br>• **Reason**: VLM 기반의 물리적 상식 및 충돌 위험성 인과 추론 | • 휴머노이드 로봇 및 자율주행을 위한 차세대 피지컬 AI 파운데이션 월드 모델 표준 확립 |

### 2. 학습 퀴즈 (Quiz)

#### Q1. Ha & Schmidhuber의 World Models(2018)에 대한 설명 중 가장 옳지 않은 것은?
1. 시각 모델(V)은 변분 오토인코더(VAE)를 사용하여 고차원 픽셀 이미지를 저차원 잠재 벡터로 압축한다.
2. 기억 모델(M)은 MDN-RNN을 사용하여 과거 이력과 현재 행동을 바탕으로 다음 시점 잠재 상태의 확률 분포를 예측한다.
3. 제어기(C)는 수억 개의 파라미터를 가진 초대형 심층 신경망이어야만 복잡한 환경 제어가 가능하다.
4. "꿈속에서의 학습(Learning in the Dream)"을 통해 실제 환경과 상호작용하지 않고도 제어기를 훈련시킬 수 있다.

> **정답**: **3번**  
> **해설**: World Models의 가장 큰 장점 중 하나는 시각 모델($V$)과 기억 모델($M$)이 환경의 복잡한 물리 법칙과 표현을 모두 흡수해 주었기 때문에, 제어기($C$)는 파라미터 수가 극히 적은(불과 수백~수천 개) 단순한 1-계층 선형 모델(Linear Controller)로도 충분히 강력하다는 점입니다.

---

#### Q2. Google DeepMind의 Genie(Generative Interactive Environments)가 기존 비디오 생성 모델과 구별되는 가장 결정적인 특징은?
1. 오직 텍스트 프롬프트만을 입력받아 고정된 길이의 감상용 비디오를 생성한다.
2. 잠재 행동 모델(LAM)을 통해 사용자의 실시간 조작 입력에 물리적으로 반응하는 인터랙티브 환경을 생성한다.
3. 실제 비디오를 학습할 때 사람이 조작한 키보드 및 게임패드 입력 레이블이 필수적으로 요구된다.
4. 강화학습의 정책 신경망 훈련에는 활용될 수 없으며 순수 오락용 게임 엔진으로만 동작한다.

> **정답**: **2번**  
> **해설**: Genie는 일방적으로 시청하는 정적 비디오 생성을 넘어, 사람의 레이블이 없는 비디오로부터 잠재 행동(Latent Action)을 스스로 깨우쳐 사용자의 키보드/컨트롤러 입력에 실시간으로 반응하며 다음 프레임을 생성하는 조작 가능한(Interactive) 월드 모델입니다.

### 3. 강화학습 마스터클래스 20개 챕터 대단원의 여정

도로시, 지니, 토토, 그리고 호진 교수님과 함께 1장부터 20장까지 달려온 대단원의 여정을 한눈에 정리합니다:

```
[강화학습 20개 챕터 지능의 진화 로드맵]

PART 1: 강화학습의 기초와 수학적 토대
├─ 01강: 강화학습이란 (상호작용, 보상, 탐색과 활용)
├─ 02강: 확률과 기초수학 (확률분포, 기댓값, 미분, 행렬)
├─ 03강: 밴디트 문제 (ε-greedy, UCB, 점진적 갱신)
├─ 04강: 마르코프 과정 (상태 전이, 마르코프 성질)
└─ 05강: 마르코프 결정 과정 (MDP, 할인율, 반환값, 정책)

PART 2: 벨만 방정식과 가치 기반 고전 알고리즘
├─ 06강: 벨만 방정식 (벨만 기대 방정식, 벨만 최적 방정식)
├─ 07강: 동적 프로그래밍 (정책 평가, 정책 반복, 가치 반복)
├─ 09강: 몬테카를로법 (MC 정책 평가, ε-탐욕 제어, 중요도 샘플링)
└─ 10강: TD법 (1스텝 TD, SARSA, Q-러닝)

PART 3: 심층 강화학습과 신경망 근사
├─ 11강: 신경망과 Q 러닝 (DeZero, 선형 회귀, 인공신경망)
└─ 12강: DQN (OpenAI Gym, 경험 리플레이, 타깃 네트워크, 아타리)

PART 4: 정책 기반 강화학습과 현대 고급 알고리즘
├─ 13강: 정책 경사법 (기초 정책 경사, REINFORCE 개념)
├─ 14강: 한 걸음 더 (심층 강화학습 알고리즘 계보와 로드맵)
├─ 15강: 정책 기반 에이전트 (로그 미분 트릭, 점수 함수, REINFORCE 구현)
├─ 16강: 액터-크리틱 (QAC, AAC, TDAC, A3C, A2C, 연속 가우시안 제어)
└─ 17강: TRPO와 PPO (신뢰 구역, 대리 목적 함수, PPO-Clip, GAE)

PART 5: 초거대 AI와 물리적 세계로의 도약
├─ 18강: LLM과 강화학습 (RLHF, Bradley-Terry 보상 모델링, DPO, GRPO)
├─ 19강: 게임과 강화학습 (AlphaGo, AlphaZero, AlphaStar, OpenAI Five)
└─ 20강: 월드 모델 (World Models, Dreamer, Genie, NVIDIA Cosmos)
```
