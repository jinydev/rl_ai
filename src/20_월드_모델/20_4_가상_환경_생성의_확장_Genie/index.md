# 20.4 가상 환경 생성의 확장: Genie

**그림 20-4** 스케치북에 파스텔로 쓱쓱 그린 2D 플랫폼 게임 스테이지가 허공에 생생한 2.5D 인터랙티브 플레이 게임 월드로 즉각 살아나 조작되는 Genie 마법을 체험하는 도로시와 지니
![가상 환경 생성의 확장 Genie](./20_4_가상_환경_생성의_확장_Genie.png)

> **도로시와 지니의 상상 공방**:
> "우리가 강화학습 에이전트를 훈련시키려면 지금까지는 프로그래머가 유니티(Unity)나 파이게임(Pygame)으로 복잡한 게임 환경 코드를 한 줄 한 줄 직접 짜야 했어요.
> 그런데 2024년 구글 딥마인드가 발표한 **Genie(Generative Interactive Environments)**는 세상을 완전히 뒤흔들었습니다. 인터넷의 게임 플레이 동영상을 보고 스스로 조작 메커니즘을 깨우친 뒤, **어린아이가 크레파스로 스케치북에 대충 그린 그림이나 사진 단 한 장만 보여주면 그 그림을 키보드로 직접 점프하고 달릴 수 있는 실시간 인터랙티브 게임 세계로 즉시 변환**해 냅니다!"

---

### 1. Genie (Generative Interactive Environments) 개요

**Genie(Google DeepMind, Bruce et al., 2024)**는 텍스트 프롬프트, 손그림 스케치, 실사 사진 등 **단 한 장의 정적 이미지를 입력받아, 사용자가 컨트롤러로 실시간 조작할 수 있는 무한한 인터랙티브 가상 세계를 생성**하는 110억 개 파라미터(11B) 규모의 파운데이션 월드 모델입니다.

전통적인 비디오 생성 모델(Sora, Runway 등)은 한번 생성을 시작하면 관객처럼 멍하니 바라봐야 하는 '수동적(Passive) 비디오'를 출력할 뿐입니다. 반면 Genie는 **"인간이나 에이전트의 키보드/게임패드 입력에 실시간으로 반응하여 물리적으로 일관된 다음 프레임을 생성하는 조작 가능한(Interactive) 비디오 세계"**를 만들어냅니다.

```
[전통적 비디오 생성 vs Genie 인터랙티브 월드 모델]

1. 전통적 생성 모델 (Passive Video):
   프롬프트 입력 ──> [ 비디오 생성 모델 ] ──> 정해진 재생 영상 (상호작용 불가, 조작 불가)

2. Genie 월드 모델 (Interactive World):
   이미지 1장 ──> [ Genie 월드 모델 ] <── 사용자/에이전트 행동 입력 (점프, 달리기 등)
                         │
                         ▼
             실시간으로 행동에 반응하며 물리 법칙에 맞게 무한 생성되는 플레이 환경
```

### 2. Genie의 핵심 아키텍처와 3대 구성 요소

Genie가 별도의 사람 레이블(어떤 버튼을 눌렀는지에 대한 조작 기록) 없이 인터넷의 무수히 많은 2D 비디오만을 보고 상호작용 가능한 게임을 만들어내는 비결은 3개의 정교한 모델 파이프라인에 있습니다:

```
[Genie의 3대 모듈 학습 파이프라인]

          비디오 프레임 시퀀스 (x_1, x_2, ..., x_T)
                         │
        ┌────────────────┼────────────────┐
        ▼                                 ▼
┌──────────────────┐            ┌──────────────────┐
│  시공간 비디오   │            │   잠재 행동 모델 │
│  토크나이저      │            │   (LAM)          │
│  (ST-Tokenizer)  │            └────────┬─────────┘
└───────┬──────────┘                     │ 이 프레임 전이를 일으킨
        │ 이산 토큰 z_t                  ▼ 잠재 행동 a_t (8개 이산 행동)
        └──────────────┬─────────────────┘
                       ▼
        ┌──────────────────────────────┐
        │   다이내믹스 모델            │ ──> 시공간 트랜스포머 (ST-Transformer)
        │   (Dynamics Model)           │     과거 토큰 + 행동 a_t로부터 다음 토큰 z_{t+1} 생성
        └──────────────────────────────┘
```

#### 1) 시공간 비디오 토크나이저 (ST-Tokenizer)
* 비디오의 각 프레임을 고차원 픽셀에서 컴팩트한 이산 토큰(Discrete Tokens)으로 압축합니다.
* 공간적(Spatial) 특징뿐 아니라 시간적(Temporal) 연속성을 동시에 고려하는 VQ-GAN 아키텍처를 적용하여 연산 복잡도를 대폭 낮춥니다.

#### 2) 잠재 행동 모델 (Latent Action Model, LAM)
* **Genie의 가장 천재적인 발명품**: 인터넷의 수많은 비디오에는 플레이어가 점프 키를 눌렀는지, 오른쪽 방향키를 눌렀는지에 대한 키 입력 로그가 없습니다.
* LAM은 프레임 $x_t$와 다음 프레임 $x_{t+1}$의 시각적 변화를 비교하여, **"어떤 미지의 잠재 행동 $a_t \in \{0, 1, \dots, 7\}$가 이 화면 변화를 일으켰는가?"**를 완전 비지도 학습(Unsupervised Learning)으로 스스로 유추해 냅니다.
* 결과적으로 상, 하, 좌, 우, 점프 등 8가지의 일관된 가상 액션 토큰이 사람의 개입 없이 자동으로 학습됩니다.

#### 3) 다이내믹스 모델 (Dynamics Model: ST-Transformer)
* 110억 파라미터 크기의 초대형 시공간 트랜스포머 모델입니다.
* 과거의 비디오 토큰 시퀀스 $z_{1:t}$와 사용자가 컨트롤러로 입력한 행동 $a_t$를 조건(Condition)으로 받아, 자기회귀(Autoregressive) 방식으로 다음 프레임의 토큰 $z_{t+1}$을 실시간 생성합니다.

### 3. 강화학습 에이전트 훈련의 새로운 지평

Genie는 단순히 사람이 게임을 즐기는 도구를 넘어, **강화학습 에이전트의 무한한 시뮬레이터 요람** 역할을 수행합니다:

1. **무한한 훈련 환경 자동 생성 (Curriculum Generation)**:
   - 개발자가 맵을 일일이 제작할 필요 없이, 텍스트 프롬프트로 "용암이 끓어넘치는 지하 던전", "바람이 심하게 부는 빙판 지대" 등을 지시하면 매 순간 새로운 물리 환경이 생성됩니다.
2. **에이전트의 일반화(Generalization) 성능 극대화**:
   - 에이전트는 하나의 고정된 게임 환경이 아니라, Genie가 실시간으로 무한 생성해 내는 수백만 개의 다양한 가상 세계에서 훈련받음으로써 미지의 환경에서도 당황하지 않는 궁극의 일반화 제어 능력을 체득하게 됩니다.
