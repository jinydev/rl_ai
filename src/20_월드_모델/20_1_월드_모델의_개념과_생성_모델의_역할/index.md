# 20.1 월드 모델의 개념과 생성 모델의 역할

**그림 20-1** 안개 자욱한 호수의 징검다리를 건너기 전, 생성형 월드 모델 수정 구슬로 미래의 파문과 안전한 다음 발판을 미리 투영해 보는 도로시와 지니

---

> **호진 교수님의 강좌 노트**:
> "1943년 인지과학자 케네스 크레이크(Kenneth Craik)는 '생명체는 외부 세계의 작동 방식을 머릿속에 축소 모형(Small-scale Model)으로 구축하여, 실제로 위험에 뛰어들지 않고도 여러 행동의 결과를 미리 시뮬레이션해 봄으로써 생존 확률을 극대화한다'고 갈파했습니다.
> 인공지능 분야에서 이것을 수학적으로 구현한 것이 바로 **월드 모델(World Model)**입니다. 최근 확산 모델(Diffusion Model), 변분 오토인코더(VAE), 비디오 생성 트랜스포머 등 **생성 모델(Generative Models)**의 폭발적인 발전이 강화학습과 결합하면서, 에이전트가 완벽한 물리적 상상력을 갖추게 되었습니다."

---

### 1. 월드 모델의 정의와 인지과학적 배경

#### 1) 정의
**월드 모델(World Model)**은 에이전트를 둘러싼 물리적 환경의 시공간적 인과 역학(Spatiotemporal Dynamics)을 학습하여, **현재의 관측(Observation $o_t$)과 행동(Action $a_t$)으로부터 미래의 상태(Next State $s_{t+1}$)와 보상($r_{t+1}$)을 예측하는 내적 신경망 시뮬레이터**입니다.

#### 2) 인지과학의 정신 모형 (Mental Model)
* 사람이 날아오는 야구공을 잡을 때, 뇌는 중력 가속도 $g=9.8\,\text{m/s}^2$와 공기 저항 미분방정식을 수치해석적으로 풀지 않습니다.
* 유아기부터 수많은 시각 경험을 통해 형성된 직관적 물리 상상력(Mental Model)을 통해 "저 궤적으로 던져졌으니 0.5초 뒤 내 글러브 위치에 도달할 것이다"를 즉각적으로 예측합니다.

#### 3) 제어이론의 동역학 모델 (System Dynamics & MPC)
* 전통적인 최적 제어(Optimal Control) 및 모델 예측 제어(MPC)에서 시스템 전이 함수 $x_{t+1} = f(x_t, u_t)$를 세우고 수평선(Horizon) $H$만큼 미래를 시뮬레이션하여 최적 제어 입력 $u_t^*$를 계획하는 원리와 직결됩니다.

---

### 2. 강화학습 기법의 2 $\times$ 2 구분 체계

강화학습 알고리즘은 **"환경 모델(Model)을 사용하는가?"**와 **"가치(Value)와 정책(Policy) 중 무엇을 학습하는가?"**라는 두 축을 기준으로 명확히 구분됩니다:

| 구분 | 가치 기반 (Value-based) | 정책 기반 (Policy-based / Actor-Critic) |
| :--- | :--- | :--- |
| **모델 프리 (Model-free)**<br>*(환경 모델 없음)* | **Q-Learning, SARSA, DQN**<br>환경과 끝없이 상호작용하며 $Q(s,a)$ 추정 | **REINFORCE, A2C/A3C, PPO, TRPO**<br>환경의 전이 확률 없이 정책 그래디언트 직접 최적화 |
| **모델 기반 (Model-based)**<br>*(환경 모델 구축 & 시뮬레이션)* | **Dyna-Q, MCTS (AlphaGo Zero)**<br>모델을 통해 가상의 경험을 생성하여 가치 함수 갱신 | **World Models (Ha & Schmidhuber), Dreamer, MuZero**<br>잠재 공간 시뮬레이터 내부에서 정책과 가치를 동시 최적화 |

### 3. 생성 모델(Generative Model)이 월드 모델에서 수행하는 핵심 역할

과거 1990년대의 모델 기반 강화학습(Dyna-Q 등)은 테이블이나 단순 선형 회귀로 상태 전이를 예측했기 때문에, 아타리 게임이나 고해상도 카메라 영상과 같은 고차원 픽셀 환경에서는 모델 학습이 불가능했습니다.

현대 월드 모델이 폭발적으로 부활한 결정적 원동력은 바로 **딥러닝 생성 모델(Generative Models)**의 눈부신 발전입니다:

```
[월드 모델에서 생성 모델의 3대 핵심 역할]

1. 고차원 감각의 저차원 압축 (Perceptual Compression):
   고해상도 픽셀 이미지 (64x64x3 = 12,288차원) ──[ VAE / VQ-VAE / Diffusion ]──> 컴팩트한 잠재 벡터 z (32차원)

2. 시간적 미래 예측과 다중 가능성 모델링 (Multimodal Future Prediction):
   현재 잠재 상태 (z_t) + 행동 (a_t) ──[ RNN / Transformer / DiT ]──> 미래 잠재 상태 분포 P(z_{t+1} | z_t, a_t)

3. 상상속의 롤아웃과 보상 예측 (Imagined Rollouts & Reward Prediction):
   실제 환경 접근 0회! 오직 잠재 공간 내부에서 수만 스텝의 미래를 병렬 상상하여 보상과 가치 추정
```

#### 1) 지각적 압축 (Perceptual Compression)
* 원시 화면 픽셀은 조명의 미세한 깜빡임, 배경 먼지 등 정책 결정에 무관한 노이즈가 너무 많습니다.
* **VAE(Variational Autoencoder)**나 **VQ-VAE(Vector Quantized VAE)**를 사용하면 고차원 이미지를 에이전트의 위치, 장애물과의 거리 등 핵심 물리 정보만 보존된 32~64차원의 **잠재 공간(Latent Space, $z_t$)**으로 극적으로 압축할 수 있습니다.

#### 2) 확률적 미래 전이 생성 (Stochastic Transition Modeling)
* 환경의 미래는 하나로 고정된 결정론적 세계가 아닙니다. 적이 왼쪽으로 올 수도 있고 오른쪽으로 올 수도 있는 확률적(Stochastic) 환경입니다.
* 생성 모델은 단일 예측값 대신 **미래 상태의 조건부 확률 분포 $P(z_{t+1} \mid z_t, a_t)$**를 생성해 낼 수 있어, 다중 경로(Multimodal Futures)에 대비한 강건한 정책을 학습시킵니다.

#### 3) 무비용 가상 롤아웃 (Zero-cost Imagination Rollout)
* 로봇이 현실에서 1만 번 넘어지면 관절 모터가 파손되지만, 생성 모델 내부의 잠재 공간에서는 1초에 수백만 번의 낙하 시나리오를 GPU 메모리 안에서 아무런 물리적 비용 없이 시뮬레이션할 수 있습니다.
