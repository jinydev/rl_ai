## 09.1.0.3 상태 전이 확률과 보상 함수 수식 기호 해부

수식으로 표현하면 **상태 전이 확률 *p*(*s*' | *s*, *a*)**와 **보상 함수 *r*(*s*, *a*, *s'*)**를 완벽하게 이용할 수 있었습니다. 

![상태 전이 확률과 보상 함수 수식 기호 해부](./img/01_4_transition_prob_and_reward_function.png)
**그림 09-1-1c** 알려진 환경 모델의 2대 수학 기둥: 상태 전이 확률 p(s'|s,a)와 보상 함수 r(s,a,s')의 수식 기호 해부

> "알려진 환경 모델을 수학적으로 표현한 핵심 기호입니다. p(s'|s,a)는 현재 상태 s에서 행동 a를 했을 때 다음 상태 s'로 전이될 조건부 확률이며, r(s,a,s')는 그 전이 과정에서 즉각 주어지는 보상 함수입니다. 동적 프로그래밍은 바로 이 두 가지 수학 공식을 완벽히 알고 있다는 전제하에 벨만 방정식을 풀어 최적 가치를 계산했습니다."

## 09.1.0.4 결정적 상태 전이 함수

만약 미끄러짐이 없는 완벽한 환경이라면 상태 전이가 결정적(Deterministic)이므로, 다음 상태를 나타내는 수학 함수 *s'* = *f*(*s*, *a*)로 딱 떨어지게 나타낼 수도 있었습니다.

![결정적 상태 전이 함수](./img/01_5_deterministic_state_transition_func.png)
**그림 09-1-1d** 미끄러짐이 없는 완벽한 환경에서의 결정적 상태 전이 함수 s' = f(s, a)

> "바람이 불거나 미끄러짐이 전혀 없는 완벽한 환경이라면 확률이 아닌 결정적 함수 s' = f(s, a)로 나타낼 수 있습니다. 현재 상태와 행동을 함수에 넣으면 다음 상태가 단 하나로 확정되어 나옵니다. 에이전트는 수학 함수 f를 가지고 모든 미래를 한 치의 오차도 없이 미리 예측할 수 있습니다."

## 09.1.0.5 게임기 소스 코드를 쥔 에이전트의 사전 시뮬레이션

이처럼 환경 모델이 알려진 문제에서는 에이전트 측에서 '상태, 행동, 보상'의 전이를 컴퓨터 시뮬레이션으로 완전히 계산할 수 있었습니다.

![게임기 소스 코드를 손에 쥔 에이전트의 사전 시뮬레이션](./img/01_6_planning_in_memory_simulation.png)

> "환경 모델을 안다는 것은 마치 게임기 본체의 내부 소스 코드를 에이전트가 통째로 쥐고 있는 것과 같습니다. 적이 언제 어디서 나타날지, 점수가 어떻게 계산될지 코드를 뜯어보면 다 알 수 있으므로, 에이전트는 실제로 게임을 플레이하지 않고도 메모리 속에서 모든 수를 미리 시뮬레이션하여 최적의 전략을 세울 수 있습니다."

| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |

> **💡 확률분포(Probability Distribution)란?**

### 확률 분포를 통한 기댓값 계산

이 확률 분포를 알면 이론적 기댓값(Expected Value)을 다음과 같이 계산할 수 있습니다:

> ### (식 9.1-1) 이산 확률 변수의 이론적 기댓값
> E[*X*] = ∑<sub>*x*</sub> *x* · *P*(*X* = *x*)

> "확률 분포가 주어졌을 때 이론적 참 기댓값을 구하는 공식입니다. 기댓값 E[X]는 나올 수 있는 모든 사건 값 x에 그 사건이 발생할 엄밀한 수학적 확률 P를 곱한 뒤 전부 더해주는 가중합입니다. 주사위 눈의 합 2부터 12까지 각 값에 해당 확률을 곱해 합산하면 이론적 중심값을 얻게 됩니다."

### 파이썬 코드로 샘플 모델 구현하기

```python
import numpy as np

def sample(dices=2):
    x = 0
    for _ in range(dices):
        x += np.random.choice([1, 2, 3, 4, 5, 6])
    return x

print(sample()) # 실행할 때마다 10, 4, 8 등 무작위 표본 반환
```

## 09.1.3.1 수학적 표현: 표본 평균 공식

### 수학적 표현: 표본 평균 공식

수학적으로 몬테카를로법은 수집한 무작위 표본(*s*<sub>*i*</sub>)들의 **표본 평균(Sample Mean)**으로 참 기댓값 *V*를 추정합니다:

> ### (식 9.1-2) 표본 평균을 이용한 가치 추정
> *V* ≈ 1 / *N* ∑<sub>*i*=1</sub><sup>*N*</sup> *s*<sub>*i*</sub>





![표본 평균 수식 기호 해부](./img/05_sample_mean_formula_breakdown.png)

> "표본 평균의 수학적 정의식입니다. 에이전트가 현실 세계에서 직접 부딪히며 측정한 N개의 실제 경험 데이터 s_i를 전부 더한 뒤, 시행 횟수 N으로 나누어 산술 평균 V를 구합니다. 이것이 몬테카를로법에서 가치 함수를 추정하는 가장 기초적인 수식입니다."

# 09.1 몬테카를로법 기초
## 09.1.3.2 수식 돋보기: 표본 평균 공식 3대 블록 해부

#### 💡 수식 돋보기: 표본 평균 공식 *V* ≈ 1 / *N* ∑ *s*<sub>*i*</sub> 기호 해부

이 간단한 수식은 몬테카를로 기법 전체를 관통하는 핵심 기둥입니다. 기호 하나하나를 뜯어보면 다음과 같습니다:

1. ***V* ≈ (가치 추정치)**:
   * 환경의 완전한 확률 분포를 알 때 구하는 이론적 참값 E[*X*] 대신, 실제 표본들로 추정한 값임을 물결 기호(`≈`)로 나타냅니다.
2. **1 / *N* (시행 횟수 정규화)**:
   * 지금까지 수집한 전체 표본의 개수 *N*으로 나누어 산술 평균을 만드는 정규화 연산자입니다.
3. **∑<sub>*i*=1</sub><sup>*N*</sup> *s*<sub>*i*</sub> (경험 표본의 누적 총합)**:
   * 에이전트가 1번째부터 *N*번째까지 실제로 환경과 부딪히며 관측한 모든 표본 데이터의 합산입니다.

![표본 평균 공식 3대 블록 기호 해부](./img/05_2_sample_mean_three_blocks_breakdown.png)
**그림 09-1-5a** 표본 평균 공식 V ≈ (1/N) ∑ s_i의 3대 핵심 블록 기호 해부 인포그래픽

> "표본 평균 공식을 3대 블록으로 분해해 보겠습니다. N분의 1은 데이터 개수로 나누어 주는 정규화 배수이고, 시그마 s_i는 에이전트가 수집한 모든 경험값들의 총합입니다. 대수의 법칙에 의해 시행 횟수 N이 커질수록 이 표본 평균은 이론적 참 기댓값 E[S]로 오차 없이 수렴합니다."

### 파이썬 일반 평균 코드 구현

```python
samples = []
for _ in range(trial):
    s = sample()

V = sum(samples) / len(samples) # 표본 평균 계산
print("추정 기댓값 V:", V) # 출력 결과: 6.98 (참값 7.0에 근접!)
```

## 09.1.3.4 대량 데이터 누적 시 메모리 한계와 비효율

### 메모리 절약의 혁명: 증분 갱신(Incremental Update)

하지만 샘플 데이터가 100만 개, 1억 개로 늘어난다면 어떨까요? 모든 샘플을 `samples` 리스트에 담아두고 매번 `sum()`을 계산하면 컴퓨터 메모리가 부족해지고 연산 속도가 심각하게 느려집니다. 1억 개의 주사위 눈을 메모리에 보관하려면 수백 메가바이트의 RAM이 소모되고, 새로운 주사위를 던질 때마다 과거 1억 개의 데이터를 처음부터 다시 더해야 하는 끔찍한 비효율이 발생합니다.

이를 해결하기 위해, 과거 데이터를 일일이 보관하지 않고 오직 **직전 가치 *V*와 시행 횟수 *n* 딱 2개만 기억**하여 실시간으로 평균을 업데이트하는 **증분 갱신(Incremental Update)**을 사용합니다:

> ### (식 9.1-3) 평균의 증분 갱신 점화식
> *V*<sub>new</sub> = *V*<sub>old</sub> + 1 / *n* (*s* − *V*<sub>old</sub>)

> "이 거대한 메모리 낭비를 해결하기 위해 이호진 교수님이 제시하는 해법이 바로 증분 갱신입니다. 과거의 수억 개 데이터를 일일이 보관하지 않고, 오직 직전 평균값 V 하나와 현재 시행 횟수 n만 기억하면서 최신 데이터를 즉시 반영하는 놀라운 점화식입니다."

## 09.1.3.8 증분 갱신 유도 1단계: 일반 평균 정의식

1. **시작점: *n*개의 데이터에 대한 일반 평균 정의식**:

2. **마지막 데이터 *s*<sub>*n*</sub>만 밖으로 떼어내기**:
   *V*<sub>*n*</sub> = 1 / *n* ( ∑<sub>*i*=1</sub><sup>*n*−1</sup> *s*<sub>*i*</sub> + *s*<sub>*n*</sub> )

> "유도의 2단계, 거대한 합에서 가장 최근에 들어온 마지막 데이터 s_n 하나만을 밖으로 분리해 냅니다. 그러면 분자는 과거 (n-1)개 데이터들의 합과 최신 데이터 s_n의 덧셈 형태로 깔끔하게 쪼개집니다."

## 09.1.3.10 증분 갱신 유도 3단계: 직전 평균 치환

3. **직전 평균 *V*<sub>*n*−1</sub>과의 관계 찾기**:
   직전 *n*−1개까지의 평균은 *V*<sub>*n*−1</sub> = 1 / (*n*−1) ∑<sub>*i*=1</sub><sup>*n*−1</sup> *s*<sub>*i*</sub> 이므로, 양변에 *n*−1을 곱하면:
   ∑<sub>*i*=1</sub><sup>*n*−1</sup> *s*<sub>*i*</sub> = (*n*−1) *V*<sub>*n*−1</sub>  
   이것을 2번 식에 쏙 대입합니다!

![증분 갱신 유도 3단계 직전 평균 치환](./img/06_5_derivation_step3_link_previous_mean.png)
**그림 09-1-6b3** 증분 갱신 유도 3단계: 과거 데이터들의 거대한 합을 직전 평균 (n-1)V_{n-1}로 치환하는 핵심 연결 고리

> "유도의 3단계, 과거 (n-1)개 데이터들의 합을 직전 평균 V_{n-1}과의 관계로 치환합니다. 직전 평균 V_{n-1}의 정의에 따라 과거 데이터들의 합은 정확히 (n-1) 곱하기 V_{n-1}과 같습니다. 과거의 방대한 데이터 덩어리가 직전 평균이라는 단 하나의 숫자로 압축되는 순간입니다."

## 09.1.3.11 증분 갱신 유도 4단계: 최종 점화식 완성

4. **대입하여 정리하기**:
   *V*<sub>*n*</sub> = 1 / *n* ( (*n*−1) *V*<sub>*n*−1</sub> + *s*<sub>*n*</sub> )  
   = 1 / *n* ( *n* *V*<sub>*n*−1</sub> − *V*<sub>*n*−1</sub> + *s*<sub>*n*</sub> )  
   = (*n* *V*<sub>*n*−1</sub>) / *n* + (*s*<sub>*n*</sub> − *V*<sub>*n*−1</sub>) / *n*  
   =  *V*<sub>*n*−1</sub> + 1 / *n* (*s*<sub>*n*</sub> − *V*<sub>*n*−1</sub>) 

![증분 갱신 유도 4단계 최종 점화식 완성](./img/06_6_derivation_step4_final_recurrence_formula.png)
**그림 09-1-6b4** 증분 갱신 유도 4단계: 괄호 전개와 분수 분리를 통한 최종 점화식 V_n = V_{n-1} + (1/n)(s_n - V_{n-1})의 대수적 완성

> "유도의 4단계, 치환된 식을 괄호 전개하고 분수를 분리하여 정리합니다. (n-1)을 n으로 나누어 1 빼기 n분의 1로 바꾸고 전개한 뒤 V_{n-1}로 묶어주면, 마침내 V_n = V_{n-1} + (1/n)(s_n - V_{n-1})이라는 기적의 증분 점화식이 유도됩니다."

## 09.1.3.13 증분 갱신 3대 구성요소 상호작용 메커니즘

#### 수식 돋보기: 증분 갱신 공식 기호 해부

과거 데이터를 모두 버려도 수학적으로 완벽한 평균이 유지되는 비밀은 바로 이 점화식 구조에 있습니다:

1. ***V*<sub>old</sub> (*V*<sub>*n*−1</sub>, 기존 추정치)**:
   * 지금까지 누적된 경험으로 알고 있는 현재의 가치 추정치입니다.
2. ***s* − *V*<sub>old</sub> (*s*<sub>*n*</sub> − *V*<sub>*n*−1</sub>, 오차 신호, Error)**:
   * 이번에 새로 관측한 표본 *s*가 기존 지식 *V*<sub>old</sub>와 얼마나 차이가 나는지를 나타내는 예측 오차입니다.
   * 새 표본이 내 생각보다 컸다면 양수(+), 작았다면 음수(-)가 나와 가치를 밀거나 당겨줍니다.
3. **1 / *n* (학습 보폭 / 학습률)**:
   * 새로운 오차를 기존 지식에 얼마나 반영할 것인가를 조절하는 계수입니다.
   * 시행 횟수 *n*이 커질수록 계수가 1/2 → 1/10 → 1/1000로 줄어듭니다. 즉, 초기에는 새로운 데이터에 민감하게 반응하여 빠르게 학습하다가, 경험이 많이 쌓이면 가치가 단단하게 고정되어 안정화됩니다.

![증분 갱신 3대 구성요소 상호작용 메커니즘](./img/06_8_incremental_update_component_dynamics.png)
**그림 09-1-6d** 증분 갱신 공식의 3대 요소(기존 가치, 오차 신호, 적응형 학습 보폭 1/n)의 역동적 상호작용 메커니즘

> "증분 갱신 공식을 이루는 3대 구성요소의 역동적 상호작용입니다. V_{old}는 지금까지의 경험치이고, (s - V_{old})는 이번 경험이 기존 예측과 얼마나 달랐는지를 알려주는 오차 신호입니다. 그리고 n분의 1은 그 오차를 얼마나 반영할지 결정하는 적응형 보폭입니다."

## 09.1.3.15 파이썬 초경량 증분 평균 알고리즘 구현

### 증분 평균 파이썬 구현

```python
trial = 1000
V, n = 0, 0

for _ in range(trial):
    s = sample()
    n += 1
    V += (s - V) / n # 증분 갱신 공식!
    
print("최종 증분 평균 V:", V) # 출력 결과: 7.0019... (참값 7 수렴)
```

**그림 09-1-6f** 파이썬 초경량 증분 평균 알고리즘 실행 순서도

이 코드는 과거의 수많은 표본을 단 하나도 메모리에 보관하지 않으면서도, 매 루프마다 수학적으로 완전무결한 평균값을 실시간으로 유지합니다. 

메모리 사용량은 표본이 100만 개든 100억 개든 영원히 *O*(1)(상수 크기)입니다!

> "파이썬으로 구현한 초경량 증분 평균 알고리즘입니다. 리스트를 전혀 쓰지 않고 오직 단 하나의 실수 변수 V만 유지합니다. 루프를 돌며 새로운 데이터 s가 들어올 때마다 V += (s - V) / n 한 줄로 값을 갱신하므로 메모리 사용량이 O(1), 즉 완벽한 상수로 유지됩니다."

# 09.1 몬테카를로법 기초
## 09.1.4.1 몬테카를로 기초 3대 기둥 유기적 파이프라인

오늘 학습한 몬테카를로법 기초의 핵심은 다음 3가지 기둥으로 요약됩니다:

1. **샘플 모델 (Sample Model)**:
   * 확률 분포를 전수 조사하지 않고, '시행하여 표본을 관측할 수만 있으면 충분하다'는 발상의 전환입니다. 조합 폭발이 발생하는 복잡한 환경을 극적으로 단순화합니다.
2. **표본 평균과 대수의 법칙 (Sample Mean & LLN)**:
   * 표본 평균 *V* ≈ 1 / *N* ∑ *s*<sub>*i*</sub> 공식을 통해, 표본 수 *N*이 증가할수록 추정치가 오차를 좁혀가며 참 기댓값으로 정밀 수렴합니다.
3. **초경량 증분 갱신 (Incremental Update)**:
   * *V* ← *V* + 1 / *n* (*s* − *V*) 점화식을 사용하여, 과거의 모든 데이터를 버리고도 단 2개의 변수만으로 실시간 온라인 학습을 완성합니다.

![몬테카를로 기초 3대 기둥 유기적 파이프라인](./img/07_2_three_pillars_pipeline_infographic.png)
**그림 09-1-7a** 몬테카를로법 기초 3대 핵심 기둥(샘플 모델, 표본 평균, 증분 갱신)의 유기적 알고리즘 파이프라인

> "세 기둥이 하나의 유기적 파이프라인으로 맞물려 돌아가는 메커니즘을 확인해 보세요. 샘플 모델이 현실과 상호작용하여 경험 데이터를 뽑아내면, 증분 갱신 엔진이 메모리 낭비 없이 실시간으로 표본 평균을 누적하여 마침내 환경의 참된 가치 함수로 수렴해 갑니다."
