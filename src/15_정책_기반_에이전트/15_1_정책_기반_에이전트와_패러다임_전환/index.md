### 1. MDP의 구성 요소와 에이전트 분류

강화학습 에이전트는 마르코프 결정 과정(MDP)이라는 환경과 상호작용하며 장기 누적 보상을 최대화하는 의사결정을 내립니다. 에이전트가 내부적으로 환경의 어떤 요소를 모델링하느냐에 따라 크게 3가지 축으로 분류할 수 있습니다:

1. **정책(Policy, $\pi$)**: 상태 $s$에서 어떤 행동 $a$를 취할 것인가를 결정하는 규칙 혹은 확률 분포.
2. **가치 함수(Value Function, $V$ 또는 $Q$)**: 특정 상태나 상태-행동 쌍의 장기적인 기대 누적 보상 평가치.
3. **모델(Model)**: 환경의 전이 확률 $P(s'|s, a)$ 및 보상 함수 $R(s, a)$에 대한 내적 시뮬레이터.

```
                  ┌───────────────────────────────┐
                  │      강화학습 에이전트         │
                  └───────────────┬───────────────┘
                                  │
          ┌───────────────────────┼───────────────────────┐
          ▼                       ▼                       ▼
   [ 정책 (Policy) ]      [ 가치 함수 (Value) ]      [ 환경 모델 (Model) ]
   - 상태에서 행동 매핑   - 상태/행동 장기 가치   - 전이 확률 P, 보상 R
   - 명시적 확률 분포     - 벨만 방정식 갱신      - 시뮬레이션 기반 계획
```

### 2. 가치 기반에서 정책 기반으로의 패러다임 전환

#### 1) 가치 기반(Value-based) 에이전트의 의사결정 경로
가치 기반 방법은 상태-행동 가치 함수 $Q(s, a)$를 정확히 학습하는 데 집중합니다. 정책은 가치 함수가 완성된 뒤에 탐욕적($\epsilon$-greedy) 방식으로 '간접 도출'됩니다:

$$\text{상태 } s \xrightarrow{\quad} \left[ \text{가치 신경망 } Q_\theta(s, a) \right] \xrightarrow{\quad} Q \text{값 산출} \xrightarrow{\quad} \left[ \arg\max_a / \epsilon\text{-greedy} \right] \xrightarrow{\quad} \text{행동 } a$$

이 방식은 가치 함수가 조금만 바뀌어도 최선의 행동이 급격하게 요동칠 수 있는 **암묵적 정책(Implicit Policy)** 구조를 가집니다.

#### 2) 정책 기반(Policy-based) 에이전트의 의사결정 경로
정책 기반 방법은 가치 함수를 일절 경유하지 않고, 상태 $s$를 입력받아 각 행동 $a$의 선택 확률 $\pi_\theta(a|s)$를 직접 출력하는 파라미터 $\theta$를 최적화합니다:

$$\text{상태 } s \xrightarrow{\quad} \left[ \text{정책 신경망 } \pi_\theta(a \mid s) \right] \xrightarrow{\quad} \text{행동 확률 분포 } \pi_\theta \xrightarrow{\quad} \text{샘플링 } a \sim \pi_\theta(\cdot \mid s)$$

이를 **명시적 정책(Explicit Policy)**이라 부르며, 신경망의 가중치 $\theta$를 조금씩 변경함에 따라 행동 확률도 연속적이고 매끄럽게 변화합니다.

### 3. 가치 기반 vs 정책 기반 에이전트 상세 비교

| 비교 항목 | 가치 기반 에이전트 (Value-based) | 정책 기반 에이전트 (Policy-based) |
| :--- | :--- | :--- |
| **핵심 최적화 대상** | 가치 함수 $Q(s, a)$ | 정책 $\pi_\theta(a \mid s)$ |
| **정책 도출 방식** | 가치 함수를 경유한 암묵적 도출 ($\arg\max_a$) | 신경망 출력으로 직접 확률 분포 출력 (명시적) |
| **행동 공간 적합성** | 이산적(Discrete) 행동 공간에 특화 | 이산 및 **연속적(Continuous)** 행동 공간 모두 우수 |
| **학습 가능한 최적 정책** | 주로 결정론적(Deterministic) 정책 | **확률적(Stochastic)** 정책 자연스럽게 학습 |
| **수렴 특성** | 가치 오차로 인해 진동(Chattering) 가능 | 목적 함수를 따라 점진적이고 매끄럽게 수렴 |
| **한계점 및 단점** | 무한/연속 행동 공간 탐색 불가 | 국소 최적점(Local Optima) 수렴 가능성, 높은 분산 |

### 4. 정책 함수의 매개변수화 방식

정책 신경망 $\pi_\theta$는 행동 공간의 형태에 따라 출력층의 구조와 활성화 함수를 다르게 구성합니다.

#### 1) 이산 행동 공간 (Softmax Policy)
카트폴(좌/우 2가지)이나 바둑/체스처럼 선택지가 유한한 이산 행동 공간에서는 신경망이 각 행동에 대한 선호도 로짓(Logit, $z_a$)을 출력하고, **소프트맥스(Softmax)** 함수를 거쳐 합이 1인 확률 분포를 만듭니다:

$$\pi_\theta(a \mid s) = \frac{e^{z_\theta(s, a)}}{\sum_{b \in \mathcal{A}} e^{z_\theta(s, b)}}$$

이때 에이전트는 도출된 확률 분포 $\pi_\theta$에 따라 확률적으로 행동을 샘플링하므로, 별도의 $\epsilon$-탐욕 기법을 인위적으로 섞지 않아도 **탐색(Exploration)과 활용(Exploitation)이 하나의 프레임워크로 자연스럽게 통합**됩니다.

#### 2) 연속 행동 공간 (Gaussian Policy)
로봇 팔 제어, 드론 비행, 자율주행 차량의 스티어링 휠 각도처럼 행동이 실수(Continuous Real Value)인 경우, 신경망은 단일 확률 대신 **가우시안 정규분포의 평균($\mu(s)$)과 표준편차($\sigma(s)$)**를 출력합니다:

$$a \sim \mathcal{N}\left(\mu_\theta(s), \sigma_\theta^2(s)\right), \quad \pi_\theta(a \mid s) = \frac{1}{\sqrt{2\pi}\sigma_\theta(s)} \exp\left( -\frac{(a - \mu_\theta(s))^2}{2\sigma_\theta^2(s)} \right)$$

가치 기반 방법으로는 상상조차 할 수 없었던 연속 제어 문제가 정책 신경망에서는 평균과 표준편차를 회귀 예측하는 지극히 자연스러운 딥러닝 문제로 변환됩니다.

### 5. 확률적 정책이 반드시 필요한 이유

왜 최적 정책이 항상 하나의 최선의 행동만을 고집하는 결정론적 행동($\arg\max$)이어서는 안 될까요?

1. **불완전 정보 환경 (POMDP)**:
   - 센서의 가림 현상이나 관측 노이즈로 인해 서로 다른 실제 상태 $s_1$과 $s_2$가 동일한 관찰값 $o$로 에이전트에게 전달될 때, 결정론적 에이전트는 무한 루프에 갇혀 영원히 탈출하지 못할 수 있습니다. 이때 확률적 정책은 무작위 탐색을 통해 루프를 깨고 탈출구를 찾아냅니다.
2. **적대적 환경 및 게임 (가위바위보, 포커)**:
   - 가위바위보 게임에서 에이전트가 "나는 가위만 낸다"는 결정론적 정책을 취하면 상대방에게 즉시 파훼당합니다. 최적 내시 균형(Nash Equilibrium)은 세 행동을 각각 $\frac{1}{3}$의 확률로 균등하게 취하는 **혼합 전략(Mixed Strategy)**뿐입니다.
   - 정책 기반 에이전트는 환경에 따라 필요한 최적의 확률 비율을 스스로 학습해 낼 수 있습니다.
