# 강화 학습 핵심 이론부터 문제 풀이, 심층 강화 학습까지 한 권에!

Deep Learning from Scratch 4

이 책은 '밑바닥부터' 직접 만들어보며 즐겁게 딥러닝을 익힐 수 있는 시리즈의 장점을 그대로 따랐습니다. 외부 라이브러리에 의존하지 않고 강화 학습 알고리즘을 밑바닥부터 구현하면서 배워봅니다. 코드는 최대한 간결하면서도 강화 학습에서 중요한 아이디어가 명확하게 드러나도록 짰습니다. 단계적으로 수준을 높이면서 다양한 문제에 접할 수 있도록 구성하였으니 강화 학습의 어려움과 재미를 모두 느낄 수 있을 것입니다.

* **1장** 밴디트 문제
* **2장** 마르코프 결정 과정
* **3장** 벨만 방정식
* **4장** 동적 프로그래밍
* **5장** 몬테카를로법
* **6장** TD법(Temporal Difference Learning)
* **7장** 신경망과 Q 러닝
* **8장** DQN(Deep Q Network)
* **9장** 정책 경사법
* **10장** A3C/DDPG/TRPO/레인보우 알고리즘과 심층 강화 학습

---

기본 알고리즘부터 최신 알고리즘까지 체계적으로 설명하여 입문자도 강화 학습의 기본기를 탄탄하게 다질 수 있습니다. 수식과 예시를 통해 원리부터 실제 적용 방법까지 학습할 수 있어 강화 학습을 제대로 배우고자 하는 분에게는 최고의 책이 될 것입니다.  
-- **강민재**, 성균관대학교 전자전기공학부  

LLM의 근간을 이루는 강화 학습에 대한 기초를 다루어 굉장히 시의적절하다고 생각합니다. 강화 학습에 대한 기초적인 이론과 개념을 잡고자 한다면 이 책으로 시작하기를 강력히 권합니다.  
-- **장대혁**, NLP 개발자
