# [이미지 분석 및 프롬프트 명세서] bellman_code_math_bridge.png

## 1. 교재 내 위치 및 교육적 맥락 (Pedagogical Context)
- **파일명**: `bellman_code_math_bridge.png`
- **교재 챕터**: 07.3.4 반복적 정책 평가 구현 - [식 07-3]과 코드의 1대1 대응 (`index.md` 라인 664-686)
- **캡션**: `수학과 코드의 아름다운 만남: 벨만 갱신식과 파이썬 한 줄의 1:1 완벽한 대응!`
- **교육적 목표**: 
  이론으로 배운 벨만 방정식 [식 07-3] $V_{k+1}(s) = \sum_{a} \pi(a \mid s) \{ r(s, a, s') + \gamma V_k(s') \}$과
  실제 구현 코드 `new_V += action_prob * (r + gamma * V[next_state])` 사이의 
  완벽한 일대일 대응 관계를 시각화합니다. 복잡해 보이는 수학 기호들이 실제로는 파이썬 코드 한 줄로 우아하게 번역되는 지적 희열을 도로시와 교수님의 상호작용으로 표현합니다.

## 2. 핵심 개념 및 시각적 은유 (Core Concept & Visual Metaphor)
- **핵심 개념**: 벨만 기대 방정식의 이산 연산화, 수학 수식과 알고리즘 코드의 상호 번역.
- **시각적 은유**: 
  - 대형 칠판 위에 금빛 화살표로 연결된 두 개의 영롱한 텍스트 블록:
    * 상단: 벨만 수식 $V(s) = \sum \pi [r + \gamma V(s')]$
    * 하단: 파이썬 코드 `new_V += prob * (r + gamma * V[next])`
  - 두 블록 사이에 흐르는 빛나는 마법의 번역 다리(Golden Bridge).
  - 이호진 교수님이 지휘봉으로 수식의 $\sum$과 코드의 `+=`를 가리키며 활짝 웃고, 도로시가 노트에 별표를 그리며 환호하는 모습.
- **유지해야 할 필수 콘텐츠**:
  - 수학 수식과 코드 간의 직관적 대응 연결.
  - 순백색 배경.
