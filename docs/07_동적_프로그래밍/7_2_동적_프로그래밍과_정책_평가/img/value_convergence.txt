- **주제**: 수축 사상(Contraction Mapping)과 깔때기 수렴 원리
- **배경**: #FFFFFF (순백색 배경, 슬라이드 프레임/테두리 없음)
- **비율**: 1:1 정사각형

## 2. 시각적 구성 요소 및 구도
- **설명**: 어떤 엉뚱한 임의의 초깃값 구슬들을 넣더라도, 할인율 gamma < 1이라는 수학적 중력 깔때기를 통과하며 오차가 절반씩 줄어들어 오직 단 하나의 참 가치 점으로 쏙 모여드는 수렴 원리.
- **주요 구성**:
  - 중앙: 투명하고 은은하게 빛나는 나선형 깔때기
  - 구슬들: 위쪽의 흩어져 있던 다양한 색상의 시작 구슬들이 아래로 내려올수록 단 하나의 황금색 초점(v_pi)으로 모여듦
  - 도로시: 깔때기 옆에서 구슬들의 궤적을 경이롭게 지켜보는 도로시
  - 지니: '할인율 gamma 덕분에 언제나 오직 하나의 정답으로 모인단다' 설명하는 지니
  - 토토: 맨 아래로 모여서 톡 떨어지는 황금 구슬을 호기심 어린 눈으로 보는 하얀 강아지 토토
  - 배경: 순백색(#FFFFFF)

## 3. 캐릭터 가이드 준수
- 도로시 감탄, 지니 설명, 토토 호기심. 표준 복장 준수.
- **화풍**: 스튜디오 지브리 2D 애니메이션 스타일, 다크 에스프레소 브라운 외곽선(#26211E), 따뜻하고 평평한 셀 채색, 그림자 최소화.
- **배경 원칙**: 순백색(#FFFFFF) 컷아웃, 여백 충분, 텍스트 일체 배제(외국어/왜곡 텍스트 없음).

## 4. 교육적 의도
- 바나흐 고정점 정리(수축 사상)의 난해한 수학을 '어디서 시작해도 한 점으로 모이는 깔때기'라는 직관적 물리학으로 변환.
