# current_vs_next_value.png 시각 자료 명세서

## 1. 이미지 메타데이터
- **파일명**: current_vs_next_value.png
- **위치**: src/07_동적_프로그래밍/7_2_동적_프로그래밍과_정책_평가/img/
- **주제**: 현재 상태와 다음 상태 가치의 재귀적 징검다리
- **배경**: #FFFFFF (순백색 배경, 슬라이드 프레임/테두리 없음)
- **비율**: 1:1 정사각형

## 2. 시각적 구성 요소 및 구도
- **설명**: 현재 섬(상태 s)에 서 있는 도로시가, 즉각적인 사과 보상(R)을 손에 쥐고 징검다리를 건너 다음 섬(상태 s')의 할인된 황금 가치(gamma V(s'))와 결합하는 재귀적 구조.
- **주요 구성**:
  - 두 개의 공중 섬: 왼쪽 섬(현재 상태 s)과 오른쪽 섬(다음 상태 s')
  - 다리: 두 섬을 잇는 빛나는 아치형 무지개다리
  - 도로시: 왼쪽 섬에서 탐스러운 빨간 사과(+1 보상)를 안고 오른쪽 섬의 빛나는 크리스털(V(s'))을 가리킴
  - 지니: 다리 중간에서 '현재 보상 더하기 다음 가치!'를 노래하듯 지휘하는 지니
  - 토토: 도로시 앞서 징검다리를 신나게 건너는 하얀 강아지 토토
  - 배경: 순백색(#FFFFFF)

## 3. 캐릭터 가이드 준수
- 도로시 멜빵바지, 지니 안경/방울, 토토 하얀 털/하늘색 반다나.
- **화풍**: 스튜디오 지브리 2D 애니메이션 스타일, 다크 에스프레소 브라운 외곽선(#26211E), 따뜻하고 평평한 셀 채색, 그림자 최소화.
- **배경 원칙**: 순백색(#FFFFFF) 컷아웃, 여백 충분, 텍스트 일체 배제(외국어/왜곡 텍스트 없음).

## 4. 교육적 의도
- V(s) = R + gamma V(s')라는 벨만 방정식의 핵심인 '현재와 다음 상태의 연결 고리'를 시각화.
