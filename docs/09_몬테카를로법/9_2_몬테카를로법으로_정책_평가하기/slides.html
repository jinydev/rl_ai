09.2.1 가치 함수를 몬테카를로법으로 구하기

가치 함수의 복습과 정의식

강화학습에서 ‘상태 가치 함수’란 에이전트가 어떤 상태에서 출발하여 앞으로 얻을 수 있는 장기적인 기대 수익의 총합을 뜻합니다:

[강의 스크립트]

vπ(s) = Eπ[Gt | St = s]

그림 09-2-2 가치 함수 정의식 vπ(s) = Eπ[Gt | St = s]의 기호별 의미(정책, 출발 상태, 조건부 기댓값)를 칠판에서 해설하는 장면

“상태 가치 함수 v_pi(s)의 수학적 정의를 살펴봅니다. 특정 상태 s에서 출발하여 고정 정책 파이를 따랐을 때 미래에 받게 될 감가 누적 보상들의 총합인 지 티의 조건부 기댓값으로 엄밀하게 정의됩니다.”

09.2.1 가치 함수를 몬테카를로법으로 구하기

💡 수식 돋보기: 가치 함수 정의식 기호 해부

가치 함수 수식의 기호를 하나하나 뜯어보면 강화학습의 평가 원리가 한눈에 들어옵니다:

  1. **v<sub

[강의 스크립트] π</sub>(s) (상태 s의 참 가치)**:

  • 정책 π를 고정하고 따랐을 때, 에이전트가 현재 상태 s에 서 있다는 사실 자체만으로 기대할 수 있는 장기적인 잠재 가치 점수입니다.
    1. Eπ[·] (정책 조건부 기댓값):
  • 미래에 어떤 상태로 미끄러질지(환경의 확률성)와 에이전트가 어떤 행동을 고를지(정책의 확률성)를 모두 고려하여 구한 이론적인 가중 평균값입니다.
    1. Gt (시점 t의 누적 할인 수익, Return):
  • 지금 당장 손에 쥐는 1스텝 보상뿐만 아니라, 게임이 끝날 때까지 미래에 받게 될 모든 보상들을 할인율 감마로 깎아서 전부 더한 알짜배기 총수익(Gt = Rt+1 + 감마Rt+2 + 감마2Rt+3 + …)입니다.
    1. ** St = s (조건부 출발점)**:
  • “시점 t에 에이전트가 서 있는 출발 위치가 정확히 상태 s일 때”라는 수학적 단서 조건입니다.

그림 09-2-2a 가치 함수 정의식 브이 에스 = E_π[지 티 | S_t = s]의 4대 핵심 기호 정밀 해부 인포그래픽

“가치 함수 정의식에 등장하는 네 가지 핵심 기호의 역할을 분해합니다. 정책 파이, 기대수익 지 티, 출발 상태 s 조건, 그리고 확률적 조건부 기댓값 E가 결합되어 미래 보상의 기대 총량을 수학적으로 완성합니다.”

그림 09-2-2a3 출발 상태 s에서 시작하여 목표 골 지점에 도달했을 때 에이전트 손에 쥐어지는 누적 수익 표본 G 토큰

09.2.1 가치 함수를 몬테카를로법으로 구하기

이러한 모험을 n번 반복하여 얻은 실제 수익들이 바로 샘플 데이터(G<sup

[강의 스크립트] (1)</sup>, G(2), …, G(n))가 되며, 이 샘플들의 산술 평균을 구하면 가치 함수의 추정치 Vπ(s)가 완성됩니다:

Vπ(s) = (G(1) + G(2) + … + G(n)) / n = (1/n) ∑i=1n G(i)

상태 s에서 시작하여 i번째 에피소드에서 얻은 실제 수익을 G(i)라 할 때, n번의 에피소드 표본 평균으로 Vπ(s)를 추정합니다.

“동일한 상태에서 출발하여 얻은 n개의 실제 수익 샘플들을 모두 더해 n으로 나누는 산술 평균 공식입니다. 표본 수가 늘어날수록 평균 오차는 0으로 수렴하여 참 가치 함수를 빈틈없이 복원해 냅니다.”

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

즉, 수식을 다음과 같이 점화식 형태로 다시 쓸 수 있습니다:

[강의 스크립트] GC = R2
GB = R1 + 감마GC
GA = R0 + 감마GB

그림 09-2-5c 골에서 시작점으로 거슬러 올라가는 삼단계 점화식 계산 구조 (GC=R2 → GB=R1+감마GC → GA=R0+감마GB) 인포그래픽

“골 지점 직전의 C부터 B, A로 거슬러 올라가며 단 세 번의 점화식 덧셈만으로 모든 수익을 정산하는 단계별 메커니즘입니다. 중복 연산이 순식간에 사라지는 마법 같은 최적화입니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

일반화하면 어떤 임의의 시점 t에서의 수익 G<sub

[강의 스크립트] t</sub>는 다음과 같은 아름다운 재귀 점화식으로 표현됩니다:

Gt = Rt + 감마Gt+1

그림 09-2-4b 이호진 교수님이 포인터로 골 지점에서 시작 지점으로 거슬러 올라가는 역방향 징검다리 화살표를 가리키며, 이미 구한 미래 수익 Gt+1을 재활용하는 Gt = Rt + 감마Gt+1 점화식을 도로시와 지니에게 설명하는 장면

“임의의 시점 t에 대해 지 티 = R_t + 감마 * G_{t+1}로 정의되는 아름다운 재귀 점화식입니다. 최종 종료 시점에서는 G_T = 0으로 시작하여 역방향으로 완벽하게 전파됩니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

그림 09-2-5 골 지점에서부터 뒤로 걸어오며 할인율 γ를 곱해 미래 수익을 재사용하는 역방향 수익 정산 점화식 시각화

[강의 스크립트] 이호진 교수님이 역방향 징검다리 칠판을 통해 점화식의 직관적 물리 의미를 명쾌하게 설명합니다. 끝에 도달하여 결말을 안 뒤에야 각 순간의 진정한 기여도를 거꾸로 정확히 평가할 수 있습니다. —

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

💡 계산 복잡도의 기적: O(T<sup

[강의 스크립트] 2</sup>)에서 O(T)로의 대혁신!

만약 계산을 앞에서부터 순서대로(GA → GB → GC) 한다면, GA를 구할 때 R1, R2를 더하고, GB를 구할 때 R2를 또 더하는 심각한 중복 덧셈이 발생합니다. 에피소드 길이가 100스텝이라면 약 (100 × 101) / 2 &approx; 5,000번의 연산이 필요합니다.

그림 09-2-5d 정방향 누적 O(T^2) vs 역방향 누적 O(T) 계산 복잡도 극적 비교: 5,000회 중복 연산의 비효율과 100회 단일 패스의 쾌속 질주

“종료 지점에서 시작 지점을 향해 보상들을 감가율과 결합하며 누적해 내려오는 데이터 파이프라인의 완성된 순서도입니다. 하드웨어 메모리와 캐시 친화적인 알고리즘 구조를 보여줍니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

하지만 *골(Goal)에서부터 출발지를 향해 거꾸로(G*<sub

[강의 스크립트] C</sub> → GB → GA) 거슬러 올라가며 계산**하면:

  1. 맨 끝 상태 C의 수익은 즉각 보상 R2로 바로 확정됩니다 (GC = R2).
  2. 바로 앞 상태 B의 수익은 이미 구해둔 GC에 할인율 감마만 곱해서 즉각 보상 R1과 더하면 끝납니다 (GB = R1 + 감마GC).
  3. 가장 앞선 상태 A의 수익 역시 이미 구해둔 GB에 감마만 곱해서 R0와 더하면 즉시 끝납니다 (GA = R0 + 감마GB).

그림 09-2-5e 골에서 출발지를 향해 거꾸로 거슬러 올라가며 단 1회의 곱셈과 덧셈으로 상태별 수익을 확정 짓는 단계별 정산도

“정방향 계산 시 에피소드 길이 T에 대해 오브 티 제곱의 2차 시간 복잡도가 소요되지만, 역방향 재귀 정산을 적용하면 오브 티의 선형 시간으로 비약적인 속도 개선이 이루어집니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

에피소드 길이가 100스텝이어도 단 100번의 곱셈과 덧셈(O(T) 선형 시간)만으로 모든 상태의 수익 정산이 눈 깜짝할 사이에 완료됩니다! 파이썬 코드에서 에피소드 메모리 리스트를 reversed(memory)로 뒤집어 순회하는 이유가 바로 이 눈부신 계산 최적화 때문입니다.

그림 09-2-5f 파이썬 reversed(memory) 역순회 알고리즘 순서도: Goal 직전부터 거꾸로 돌며 G = gamma * G + reward 를 누적하고 가치 함수를 갱신하는 표준 순서도

[강의 스크립트] 골에서 출발지를 향해 거꾸로 거슬러 올라가는 실제 연산 흐름을 시각화했습니다. 에피소드가 수백 걸음으로 길어져도 곱셈과 덧셈 한 쌍만으로 각 상태의 수익이 즉시 정산됩니다. —

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

09.2.4 핵심 정리: 몬테카를로 정책 평가의 3대 핵심 기둥

몬테카를로 기법을 강화학습 정책 평가에 적용하는 핵심 원리는 다음 3가지 기둥으로 요약됩니다:

그림 09-2-6 몬테카를로 정책 평가의 3대 핵심 기둥(수익 표본 평균, 단일 경로 다중 수확, 역방향 재귀 정산)을 총정리하는 연구실 4인방

[강의 스크립트] 파이썬 코드에서 에이전트의 경험 리스트를 reversed(memory)로 뒤집어 for 루프를 순회하는 핵심 구현 원리입니다. 단 3줄의 파이썬 코드로 O(T) 역방향 점화식을 구현할 수 있습니다. —

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

  1. 경험 수익의 표본 평균 (Return Averaging):
    • 환경의 전이 확률 모델 p(s’ s, a)를 전혀 몰라도, 에피소드를 끝까지 완주하며 얻은 실제 수익들의 산술 평균 V<sub

[강의 스크립트] π</sub>(s) = (∑ G(i)) / n으로 참 가치 함수를 완벽하게 근사합니다.

그림 09-2-6a 제1기둥: 환경 모델 없이 완주된 에피소드 수익들의 표본 평균으로 참 가치를 수렴시키는 수익 표본 평균 인포그래픽

“몬테카를로 정책 평가를 떠받치는 3대 핵심 기둥인 표본 평균, 단일 경로 다중 수확, 역방향 재귀 정산의 전체 조감도를 한눈에 정리합니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

  1. 단일 경로 다중 상태 수확 (Multi-state Harvesting):
    • 상태마다 따로따로 출발할 필요 없이, 단 한 번의 에피소드 주행으로 경로 상에 방문한 모든 상태(A, B, C)의 수익 표본을 동시에 수확합니다.

그림 09-2-6b 제2기둥: 단 1회의 주행 경로로 방문한 모든 상태의 수익 표본을 일거에 거두어들이는 1타 다피 수확 인포그래픽

[강의 스크립트] 제1기둥인 경험 수익 표본 평균입니다. 환경의 전이 확률을 전혀 몰라도 에이전트가 직접 겪은 에피소드들의 누적 보상 평균만으로 상태의 참 가치를 정밀하게 근사합니다. —

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

  1. 초고속 역방향 재귀 정산 (Backward Recursion):
    • G<sub

[강의 스크립트] t</sub> = Rt + 감마Gt+1 점화식을 이용하여 골에서부터 거꾸로 계산함으로써, 불필요한 중복 연산 없이 O(T)의 초고속으로 모든 상태의 가치를 업데이트합니다.

그림 09-2-6c 제3기둥: 지 티 = R_t + gamma * G_{t+1} 점화식으로 O(T) 선형 시간에 모든 가치를 갱신하는 초고속 역방향 재귀 정산 인포그래픽

“제2기둥인 단일 경로 다중 상태 수확입니다. 상태마다 따로 리셋할 필요 없이 단 한 번의 여정에서 밟고 지나간 모든 상태의 수익 데이터를 동시에 획득하여 학습 속도를 극대화합니다.”

09.2 몬테카를로법으로 정책 평가하기

09.2.3 몬테카를로법 계산 효율 개선: 역방향 수익 정산

[강의 스크립트] 👨‍🏫 이호진 교수님의 직강 노트:
“몬테카를로 정책 평가의 백미는 바로 ‘끝까지 가보고 거꾸로 정산한다’는 점입니다. 인생에서도 목표를 이룬 뒤 지나온 길을 되돌아볼 때 각 순간의 가치를 비로소 명확히 평가할 수 있듯이, 몬테카를로법은 에피소드 완주 후 골에서부터 거꾸로 보상을 묶어줌으로써 복잡한 미래의 가치를 명쾌하게 밝혀냅니다.”

그림 09-2-6d 이호진 교수님의 직강 멘토링 노트: 인생에서도 목표를 이룬 후 지나온 길을 되돌아볼 때 각 순간의 가치가 명쾌해지듯, 완주 후 거꾸로 정산하는 몬테카를로의 지혜

“제3기둥인 초고속 역방향 재귀 정산입니다. 점화식 지 티 = R_t + 감마 * G_{t+1}을 통해 오브 티의 선형 시간에 에피소드 전체의 수익을 누수 없이 정산해 냅니다.”
