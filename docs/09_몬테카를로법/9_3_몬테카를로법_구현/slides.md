# 09.3 몬테카를로법 구현
## 09.3.1 환경과 상호작용: step() 메서드

에이전트가 환경 속에서 실제로 한 걸음 행동하고 그 결과를 관측할 수 있도록 해주는 핵심 통로가 바로 `env.step(action)` 메서드입니다.

```python
from common.gridworld import GridWorld

env = GridWorld()
action = 0 # 더미 행동 (예: 상)
next_state, reward, done = env.step(action)

print('next_state:', next_state) # 다음 상태: (1, 0)
print('reward:', reward)         # 즉각 보상: 0.0
print('done:', done)             # 종료 여부: False
```

- 📥 **입력 매개변수 (`action`)**: 에이전트가 선택한 행동 번호 (0: 상, 1: 하, 2: 좌, 3: 우)
- 📤 **반환 값 3총사**:
  * `next_state` (*S*<sub>*t*+1</sub>): 행동 결과 에이전트가 실제로 도착한 다음 좌표
  * `reward` (*R*<sub>*t*</sub>): 해당 스텝에서 즉시 획득한 보상 수치
  * `done`: 목표 지점(Goal)이나 함정에 도달하여 에피소드가 끝났는지 여부 (True/False)

> "에이전트가 환경과 대화하는 주문이 바로 step 메서드입니다. 행동 번호를 건네주면 환경은 다음 위치와 방금 얻은 보상, 그리고 모험이 끝났는지를 뜻하는 done 불리언 값을 돌려줍니다. 이 세 가지 정보가 학습의 원재료가 됩니다."

# 09.3 몬테카를로법 구현
## 09.3.1 경험 패키징: (상태, 행동, 보상) 메모리 버퍼

에이전트는 매 스텝마다 관측한 경험을 `(state, action, reward)` 튜플로 단단히 패키징하여 배낭 리스트 `self.memory`에 차곡차곡 누적합니다.

![step 메서드와 메모리 저장](./img/02_step_method_memory_packaging.png)
**그림 09-3-2** 행동 리모컨의 step 버튼을 눌러 얻은 보상과 다음 상태 경험을 배낭 속 memory 리스트에 패키징하여 담는 도로시와 지니 (1:1 순백색)

- 🎒 **경험 튜플 구조**: `data = (state, action, reward)`
- 📦 **에피소드 버퍼 (`self.memory`)**:
  ```python
  [(S0, A0, R0), (S1, A1, R1), ..., (S8, A8, R8)]
  ```
- ⚠️ **마지막 상태(Goal) 생략 이유**: 목표 지점에 도달하면 모험이 종료되며 목표 상태의 잔여 가치는 항상 0이므로, 갱신할 필요가 없어 메모리에 저장하지 않음

> "도로시가 리모컨의 step 버튼을 누르면 상태와 행동, 보상이 하나의 캡슐로 묶여 배낭 속 memory 리스트에 차곡차곡 저장됩니다. 단, 모험이 끝나는 마지막 골 지점은 미래 가치가 항상 0이므로 배낭에 담지 않고 앞 단계들만 모아둡니다."

# 09.3 몬테카를로법 구현
## 09.3.2 에이전트의 두뇌: RandomAgent 클래스 초기화

무작위 행동을 선택하는 확률 정책 `pi`와 각 상태의 가치 함수 `V`, 방문 횟수 `cnts`를 딕셔너리로 초기화합니다.

```python
from collections import defaultdict
import numpy as np

class RandomAgent:
    def __init__(self):
        self.gamma = 0.9        # 할인율 γ
        self.action_size = 4    # 행동 4가지 (상하좌우)
        random_actions = {0: 0.25, 1: 0.25, 2: 0.25, 3: 0.25}
        self.pi = defaultdict(lambda: random_actions) # 무작위 정책
        self.V = defaultdict(lambda: 0)               # 가치 함수 V(s)
        self.cnts = defaultdict(lambda: 0)            # 상태별 방문 횟수 N(s)
        self.memory = []                              # 에피소드 버퍼
```

- 🎲 **`defaultdict`의 지혜**: 처음 방문하는 새로운 상태도 `key error` 없이 기본값(가치 0, 방문 횟수 0)으로 자동 초기화
- 🧭 **`get_action(state)`**: `np.random.choice(actions, p=probs)`를 통해 25%의 균등한 확률로 4방향 행동을 무작위 샘플링

> "RandomAgent 클래스는 defaultdict를 사용하여 상태가 나타날 때마다 가치와 방문 횟수를 자동으로 0으로 생성합니다. 정책 pi는 상하좌우를 각각 25%의 동일한 확률로 선택하도록 설정되며, get_action 메서드를 통해 무작위로 발걸음을 결정합니다."

# 09.3 몬테카를로법 구현
## 09.3.2 몬테카를로의 심장: eval() 메서드

에피소드가 끝나면 배낭 속 경험 데이터를 `reversed()` 함수로 뒤에서부터 거꾸로 꺼내며, 역방향 점화식과 증분 갱신으로 가치 함수를 실시간 업데이트합니다.

```python
class RandomAgent:
    ...
    def eval(self):
        G = 0
        for data in reversed(self.memory): # 골에서부터 역방향 순회!
            state, action, reward = data
            G = self.gamma * G + reward    # 1. 역방향 누적 수익 계산
            self.cnts[state] += 1          # 2. 방문 횟수 증가
            self.V[state] += (G - self.V[state]) / self.cnts[state] # 3. 증분 갱신
```

- 🔄 **`reversed(self.memory)`**: 골에 도달한 직후, 지나온 발자국을 뒤에서부터 역순으로 되짚음
- ⚡ **중복 계산 0%**: 직전 스텝에서 계산된 누적 미래 수익 `G`에 할인율 `gamma`만 곱해주면 끝!
- 💾 **초경량 증분 평균**: 과거의 모든 에피소드를 저장할 필요 없이 `self.V[state]`를 점진적 갱신

> "eval 메서드는 몬테카를로 알고리즘의 심장입니다. 에피소드가 끝나면 reversed 함수로 뒤에서부터 걸어오며 누적 수익 G를 단 한 줄로 계산합니다. 그리고 증분 갱신 식을 통해 그 상태의 가치를 실시간으로 똑똑하게 업데이트합니다."

## 09.3.2 수식 돋보기: eval() 메서드의 핵심 2대 점화식 기호 해부

파이썬 코드 속의 두 줄이 수학적으로 어떤 원리로 작동하는지 칠판에서 해부해 봅시다.

![역방향 수익 계산 비유](./img/03_reversed_evaluation_chalkboard.png)
**그림 09-3-3** 칠판에 적힌 역방향 점화식과 증분 가치 갱신식을 마술봉으로 가리키며 해설하는 지니와 징검다리를 거꾸로 밟아보는 도로시 (1:1 순백색)

- **1대 점화식 (역방향 누적 수익)**:
  > ### ***G* ← *γ* · *G* + *R***
  * 골 쪽에서부터 계산해 온 미래 수익 *G*에 감가상각 *γ*를 적용하고, 현재 스텝의 즉각 보상 *R*을 더함
- **2대 점화식 (증분 가치 갱신)**:
  > ### ***V*(*s*) ← *V*(*s*) + (1 / *N*(*s*)) · (*G* - *V*(*s*))**
  * 이번 에피소드에서 관측된 실제 수익 *G*와 기존 가치 *V*(*s*)의 오차를 계산하여, 누적 방문 횟수 *N*(*s*)에 반비례하는 보폭으로 가치를 갱신

> "코드의 두 줄을 수학으로 뜯어봅시다. 첫 번째 식은 골에서부터 할인율을 곱해 미래 수익을 재사용하는 점화식이고, 두 번째 식은 이번 모험의 수익과 기존 가치의 오차를 방문 횟수로 나누어 갱신하는 식입니다. 수학과 코드가 완벽히 일치합니다."

# 09.3 몬테카를로법 구현
## 09.3.3 1,000 에피소드 실행과 가치 함수 수렴

환경과 에이전트를 결합하여 1,000번의 에피소드를 반복 실행하고, 몬테카를로법으로 완성된 가치 함수를 시각화합니다.

```python
env = GridWorld()
agent = RandomAgent()

episodes = 1000
for episode in range(episodes):
    state = env.reset()
    agent.reset()

    while True:
        action = agent.get_action(state)
        next_state, reward, done = env.step(action)
        agent.add(state, action, reward)
        if done:
            agent.eval() # 에피소드 완주 시 가치 함수 갱신!
            break
        state = next_state

env.render_v(agent.V) # 최종 가치 함수 맵 출력
```

- 🎯 **동적 계획법(DP)과의 비교**:
  * DP는 환경의 전이 확률 행렬을 모두 알고 수식을 풀었음
  * MC는 환경의 내부 규칙을 전혀 모른 채 오직 1,000번의 직접 부딪힘만으로 DP와 소수점 둘째 자리까지 완벽히 일치하는 가치 맵을 완성!

> "에피소드를 천 번 반복하여 가치 함수를 출력해 봅시다. 환경의 확률 공식을 전혀 알려주지 않았음에도, 에이전트가 스스로 모은 경험만으로 동적 계획법과 거의 완벽히 똑같은 가치 지도를 그려냅니다. 모델 프리 강화학습의 위대한 승리입니다."

## 09.3.4 핵심 정리: 몬테카를로법 구현의 3대 핵심 기둥

몬테카를로 정책 평가는 상호작용 메서드와 역방향 증분 갱신 알고리즘을 통해 우아한 코드로 완성됩니다.

![09.3 핵심 정리](./img/04_summary_core_takeaways.png)
**그림 09-3-4** 몬테카를로법 구현의 3대 핵심 기둥(step 상호작용, reversed 역방향 갱신, DP급 무결점 수렴)을 총정리하는 이호진 교수님과 연구실 4인방 (16:9 와이드)

- 1️⃣ **`step()`과 경험 튜플 버퍼**:
  * `(state, action, reward)` 캡슐로 실시간 경험을 수집하여 `memory`에 누적
- 2️⃣ **`reversed()` 역방향 증분 정산 (`eval`)**:
  * 골에서부터 되짚어가며 *G* ← *γG* + *R*과 *V*(*s*) ← *V*(*s*) + (1/*N*)(*G* - *V*(*s*))로 메모리와 연산 속도 동시 최적화
- 3️⃣ **블랙박스 환경에서의 무결점 학습**:
  * 환경 모델이 없는 상태에서도 충분한 에피소드만 있으면 이론적 참 가치 함수에 정밀 수렴
- 🚀 **다음 시간 (09.4)**: 평가를 넘어 최고의 행동을 찾아내는 **몬테카를로 정책 제어(Policy Control)와 ε-탐욕 알고리즘**을 정복합니다!
